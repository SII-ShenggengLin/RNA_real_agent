## Vaccine mRNA (`vaccine_mrna/`)

- `bnt162b2_full.fa` — 4 175 nt assembled contig; starts `GAGAATAAACTAGTATTCTTCTGGTCCCCACAGACTCAGAGAGAACCCGCCACCATG…` (matches the reverse-engineered BNT162b2 reference); ends `…GCCACACCCTGGAGCTAGCA`.
- `mrna1273_full.fa` — 4 004 nt assembled contig (partial; full coding region included); starts `GGGAAATAAGAGAGAAAAGAAGAG…`.
- Source: Jeong DE, McCoy M, Artiles KL et al., "Assemblies of putative SARS-CoV-2-spike-encoding mRNA sequences for vaccines BNT-162b2 and mRNA-1273", GitHub NAalytics (2021); sequences extracted from the published PDF. Contigs are putative assemblies and may lack terminal bases (per the source).
- Related: Nance KD & Meier JL, ACS Cent Sci 2021 (doi:10.1021/acscentsci.1c00500).

## e7_mrl_anchor_set.json (E7 mRNA-oracle capability profiling, curated 2026-08-11)

706 entries, 3 families (per family: 60 high-MRL "binder" + 60 low-MRL "negative" screening tiers + 120-anchor ranking subset evenly spaced across the filtered pool's rl ranks, tier overlap flagged in place). Generated by `experiments/curate_e7_mrl_anchor_set.py` (deterministic, assertion-checked — re-run reproduces the JSON byte-for-byte; docstring carries full protocol + exclusion registry). Pre-registration: `experiments/run_e7_mrna_oracle_profiling.py` docstring "E7 PRE-REGISTRATION". Raw GEO supplementary files cached under `experiments/lit_cache/mrl/` (md5-verified copies).

- **Source data** (both fetched 2026-08-11): Sample et al. 2019, "Human 5′ UTR design and variant effect prediction from a massively parallel translation assay", Nat Biotechnol 37:803-809; GEO GSE114002 (MPRA polysome profiling, EGFP reporter, unmodified RNA, HEK293T; `rl` = measured mean ribosome load).
  - `GSM3130435_egfp_unmod_1.csv.gz` (326,033 rows, random 50-nt 5′UTR library): https://ftp.ncbi.nlm.nih.gov/geo/samples/GSM3130nnn/GSM3130435/suppl/GSM3130435_egfp_unmod_1.csv.gz
  - `GSM4084997_varying_length_25to100.csv.gz` (106,530 rows, designed 25–100 nt library, `set` column random/human/controls/with_uaugs/no_uaugs): https://ftp.ncbi.nlm.nih.gov/geo/samples/GSM4084nnn/GSM4084997/suppl/GSM4084997_varying_length_25to100.csv.gz
- **Families**: `sample2019_egfp_random50` (GSM3130435, all rows; **in-training-distribution** for MRL models trained on this assay — GEMORNA's 5′UTR MRL head was trained on the Sample-2019 random-50 library); `sample2019_varying_length_random` (GSM4084997 set=random); `sample2019_varying_length_human` (GSM4084997 set=human, endogenous UTR-derived).
- **Filter/selection protocol** (per family, deterministic, seed 0 recorded — selection is purely rank-based): total_reads ≥ 1000; ACGT-only; dedupe by utr (max total_reads; both files are in fact duplicate-free under the filter); sort by (rl, utr) → high tier = top 60 by rl (role "binder"), low tier = bottom 60 (role "negative"), ranking subset = 120 anchors at floor(i·(N−1)/119), i=0..119 (`ranking_eligible: true`; mid-pool picks enter as role "ranking_only"). Filtered pools: 145,251 / 11,168 / 1,676.
- **Excluded subsets (registered, not in the set)**: GSM4084997 `controls` / `with_uaugs` / `no_uaugs` — small engineered uAUG-manipulation/control panels (only 27/17/17 rows pass the read filter), not natural-distribution libraries.
- **Validation status**: generator assertions all pass (n_entries == len(entries); no duplicate sequences within or across families; every high-tier rl strictly greater than every low-tier rl; length_nt == len(sequence); ranking subset == 120 per family; GSM4084997 `len` column == len(utr) row-level; GSM3130435 rows all 50 nt).
- **Run/analysis**: `experiments/results/e7_mrl_scoring.jsonl` (706/706 raw GEMORNA 5′UTR MRL oracle responses, service :8004); verdict summary `experiments/results/e7_mrna_oracle_profile_summary.json` (all 3 families verified on both E1 gates — AUROC > 0.8 and Spearman ρ ≥ 0.6; go=true); registered SelfModel `experiments/results/e7_selfmodel/self_model.json`; gate demonstration `experiments/results/e7_gate_demo.jsonl`.
