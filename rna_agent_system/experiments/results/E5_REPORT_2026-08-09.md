## 1. 摘要

E5 实验验证"约束导航"系统在**全长 mRNA 批量交付与排序**任务上的端到端能力:给定靶蛋白(物种、全长序列),系统在预注册约束矩阵(合成/表达可行性)下生成候选池,并通过三臂对照(A 规则直跑 / B 无门控 LLM / C 门控约束导航)交付 5 候选 × 3 画像排序。

- **S0(机制验证)**:经过两次 NO-GO 归因(LLM 不按效用排序 + 端点非确定)后,以**排序机制化**(系统按 U 降序强制重排,LLM 仅作 tie 仲裁)与**方案 B 混合生成池**(LinearDesign 4λ + RNARL 1 + GEMORNA 20 采样)达成 **GO**(R2 τ=1.0,LLM 仅 3 次)。
- **S1(小规模,5 靶 × 3 臂)**:三轮重跑后 **NO-GO**。最终轮 r5 中:**human 4 靶零回归**(池与交付逐位一致,确定性链路零差异);**非 human 靶 GFP 经 B0 修复从 0/315 → 12/315**(密码子表对齐生效);arm B 差异全部归因于 **LLM 非确定性**。剩余失败为生成方法层结构性:①A1AT/Insulin 的 R3 敏感性(池 λ 档距分离不足);②Insulin D1 序列多样性(λ 饱和,0.0082<2%);③GFP D2 λ 档多样性(可用档仅 λ4/λ10)。
- **结论**:系统机制层(判据、门控、排序、评估)经两阶段验证稳定且可复现;**全部剩余 NO-GO 因子均位于生成方法层**,且均已由探针实验证伪候选修复路径(A/C 分支)或拍板接受(D1/D2 结构性)。**S2(18 靶全矩阵)不建议在生成方法层未变的情况下启动**(S1 饱和下配对显著性结构性不可达,p=1.0 预期)。

## 2. 背景与目标

### 2.1 E4 教训(前序实验)
- E4 全矩阵 120 cell(20 靶 × 2 臂 × 3 种子)双终点 **NO-GO**:效率终点预算节省 74.2%(814 vs 3153)大幅过,但 memory 斜率 3 组全正(p=0.91);设计收益 4 指标 |δ| ≤0.17。
- **用户战略决策**:放弃 E4 记忆策略;E5 场景改为**全长 mRNA 批量交付 + 排序**,判据从 S0 起全量生效(E4 教训显式条目:禁止实验中途新增终点)。

### 2.2 E5 目标
1. 验证约束导航 agent(门控 C 臂)在批量设计任务上**端到端通过率、排序质量(一致性/稳定性/敏感性/最优性)、多样性(D1–D3)**达到预注册阈值;
2. 三臂对照分离**系统机制贡献**(A 规则)与 **LLM agentic 贡献**(B 自由 / C 门控);
3. 输出可交付候选(约束满足 + 排序 + 动机 notes)。

## 3. 预注册设计(定稿 v3 + 后续拍板)

### 3.1 候选池(方案 B,2026-08-07 拍板)
- 每靶点 CDS = **LinearDesign 4 λ{1,4,10}+ RNARL 1(homo_mrna,确定性)+ GEMORNA 20 采样** → 25 CDS × 9 UTR 组合 = **225 候选**(S1 v4 后 GEMORNA 30 → **315 候选**)。
- GEMORNA 采样非幂等 → 按 (target, idx) 落盘缓存 `e5_gemorna_cds_cache.json`(池可复现)。
- λ 标记:GEMORNA=-1、RNARL=-2 独立来源档(**D2 判据按 6 档计**,判据代码零改动)。

### 3.2 约束矩阵(最终形态 6 条)
| ID | 约束 | 阈值 |
|---|---|---|
| C1 | GC 滑窗 | 30–80%(100nt 滑窗) |
| C2 | 同聚物 | 无 ≥14bp(6x 以上 poly) |
| C6 | 起始区最长茎 | ≤12bp |
| C7 | 全长最长茎 | ≤30bp(LinearFold 全长 fold) |
| M1 | 全长 GC | 20–80% |
| CAI | 密码子适应度 | ≥0.8 |

> 演变轨迹:9 条(C1–C8+M1)→ 7 条(文献拍板 C5/C8 软约束)→ 5 条(C2 6→14、C3/C4 软、C6 10→12)→ 6 条(v5/v6 加 CAI;GC 35–70→30–80、CAI 0.8 先降 0.7 因 GFP 结构性不可达又恢复 0.8)。

### 3.3 三臂
| 臂 | 定义 | LLM 调用 |
|---|---|---|
| A | 规则直跑(零 LLM):按画像权重选 λ → 跨 λ 分散补足 → U 降序交付 | 0 |
| B | 无门控 LLM agent(等价替代,自由选点/排序/修复) | 2–4 次/基因 |
| C | 门控约束导航(DecisionGate/SelfModel/AuditTrail + 修复轮 ≤2) | 5–9 次/基因 |

### 3.4 判据(§9 S1 六项,最终形态)
| # | 判据 | 最终口径 |
|---|---|---|
| ① | 端到端通过率 | C ≥ 0.8 **且 C ≥ A(平局算过)**——v7 拍板(C>A 严格口径经探针证伪结构性不可达) |
| ② | 约束满足率 | C ≥ 0.9 |
| ③ | 排序质量 | R1(ρ=1.0,仅考核 C 臂)+ R2(τ≥0.8,重复间)+ R3(≥1/3 画像对分离)+ R4(top-1 全局最优) |
| ④ | 多样性 | D1(编辑距离 ≥2%)+ D2(λ ≥3 档或档距 ≥2)+ D3(pair ratio 极差 ≥3pp 或最长茎差 ≥5bp) |
| ⑤ | 方向性 | C ≥ A 至少 4/5 靶 |
| ⑥ | 预算 | BMC 记录(描述性) |

### 3.5 关卡
S0(1 靶 × C 臂 × 3 重复,5 项机制判据)→ S1(5 靶 × 3 臂,6 项)→ S2(18 靶,配对显著性 + 质量判据)。S2 规模 20→18(>1300aa 排除 Factor_VIII 2352/Zika 3420;HER2/Spike 保留如实报告)。

## 6. 归因分析(全部因子定位)

### 6.1 剩余失败因子(全部为生成方法层结构性,非系统故障)

| 因子 | 靶 | 机理 | 处置 |
|---|---|---|---|
| R3 敏感性 | A1AT/Insulin | 池内 λ 档距分离不足(偏好 λ 档 top-1 天然稳定);A 分支(λ 网格扩展)探针证伪 | 不修(拍板) |
| D1 多样性 | Insulin | 高 λ 序列趋同(λ 饱和),CDS 编辑距离 0.0082<2%;加 λ 不修(探针表④) | **接受**(拍板,λ 饱和结构性) |
| D2 λ 档多样性 | GFP | 非 human 池仅 λ4/λ10 两档过约束(λ1/GEMORNA/RNARL 0 pass);判据要求 ≥3 档或档距 ≥2 → {2,3} 档距 1 结构性不满足 | **接受**(拍板,2026-08-09) |

### 6.2 已被修复/排除的因子(机制层)
- LLM 不按 U 排序 + 端点非确定 → **排序机制化**(S0 第三案 GO 的根因修复)。
- R1 机制 bug(交付序 vs 重算 U 失配,ρ=−0.9)→ junction eval 后机制化终排。
- R4 选集失配(机制化只在 LLM 选集内排)→ 档位 A 修复 + 判据仅考核 C 臂。
- λ_pref 未实现 → 档位 A(λ_pref 进 U,W_LAMBDA=0.25→0.8)。
- GFP 空交付崩溃 → D3 空交付兜底。
- GFP 0-pass(密码子表不匹配)→ **B0**(0→12/315,CAI 0.9956–1.0)。
- RNARL 宕机 → start.sh 补 PYTHONPATH。

### 6.3 为何不建议立即启动 S2
- S1 中 constraint_rate 全 1.00、e2e 两臂平局 → S2 配对 McNemar discordant 对预期 ≈0 → p=1.0,显著性终点结构性不可达。
- 剩余 NO-GO 因子(D1/D2/R3)均为生成方法层,判据或生成策略不变则 S2 重复同一结论。
- **前置条件**:生成方法层改进(如更优的物种密码子表、多样 CDS 生成策略)或判据修订经用户拍板后再启动。

## 8. 结论与教训

### 8.1 结论
1. **机制层稳定**:两阶段 8 次运行(5 S0 + 3 S1 有效)验证了约束导航的判定、门控、机制化排序与评估链路;r4/r5 确定性链路零回归。
2. **系统端到端可达**:EPO、IL-2 两靶 6 判据全过(GO),证明在池 λ 档充足时系统交付质量达标。
3. **NO-GO 归因清晰**:全部失败因子定位至生成方法层结构性(λ 档分离、λ 饱和、可用档不足),非系统故障;A 分支/C 分支探针证伪,D1/D2 拍板接受。
4. **B0 实证**:密码子表物种对齐将 GFP 从 0-pass 结构性地提高到 12/315(CAI 1.0),验证了生成侧对齐对非 human 靶的必要性。

### 8.2 教训(机制层通用)
1. **机制化优于服从**:LLM 在 temp-0.0 下仍非确定(端点真实上限)→ 关键排序决策由机制层兜底,LLM 仅仲裁——这是 S0 GO 的决定性修复。
2. **判据与实现必须闭环**:λ_pref 定义了未实现、R4 机制化范围失配、kendall 空表 bug——三处均为"文本与代码脱节",预注册需配实现级验证清单。
3. **生成方法决定能力天花板**:约束通过率、λ 多样性、序列多样性均由生成策略设定;判据层只能观测不能创造——E5 的全部剩余 NO-GO 均印证这一点。
