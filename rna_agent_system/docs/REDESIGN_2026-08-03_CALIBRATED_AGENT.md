# 下一代系统设计文档：维护实证自我模型的 RNA 设计智能体

> **状态**：设计提案 v2（2026-08-04），**2026-08-04 已获用户批准，动工**（W1–2：P1 v2 + E1 试点）。
> **前因**：`experiments/results/HANDOFF_2026-08-03_PIVOT.md`（P0–P3 四试点判定书）。
> **约束**：保留 RNA 设计智能体身份；Layer 0–2（工具/能力/工作流）复用；Layer 3（agent 层）推倒重建；无湿实验通道。

## 0. 一页纸摘要

现行 agent 层（PipelineAgent/SpecialistAgent/CoordinatorAgent/QualityAgent/SynthesisAgent）的本质是**workflow 执行器**：LLM 做计划和评审，但系统每次运行都是失忆的，且从不检验自己工具的科学适用性。2026-08-03 的四个试点亲手量化了这两个缺陷的代价：

| 试点 | 判定 | 暴露的缺陷 |
|------|------|-----------|
| P0 预算匹配对照 | NO-GO（δ=0.278） | 优化 claim 可被采样预算混淆解释，系统无预算意识 |
| P1 接头感知优化器 | GO | 设计时目标集成可行（保留为正资产） |
| P2 适配体校准 | NO-GO（ρ=0.40，AUROC=0.356） | oracle 被用出其已验证能力边界，系统无适用性检验 |
| P3 引导 vs 非引导 | NO-GO（δ=0.222） | "诊断引导再生成"不优于纯重采样，协调知识无积累价值 |

新系统把 Layer 3 重建为以**实证自我模型（empirical self-model）**为核心的架构：agent 持久维护一张"我的工具对什么任务有什么能力"的能力地图（锚点集实测、CASF 四能力分级、随案例记忆累积演化），并且**规划、决策、发言三个环节全部以该模型为条件**——规划时 LLM 先声明本战役 claim 依赖的能力等级；执行前 DecisionGate 按能力等级裁剪动作空间（无 ranking power 的 oracle 禁止作排序目标）；结果写入前 ClaimGate 逐条校验结论不越级。画像与门控不是挂在流水线两端的检查站，而是 agent 主循环的承重件。

论文叙事：现行 agentic science 系统（含我们的旧版）只验证执行正确性、从不验证 oracle 适用性，导致优化类 claim 系统性悬空；我们提出"实证自我模型 + 双层门控"架构并用实证审计展示其必要性。

## 1. 创新点定位（经 2026-08-03 文献调研修正，2026-08-04 升级为自我模型表述）

### 1.1 修正前 → 修正后

- ~~"自校准——agent 发现 oracle 不可信"~~：**不成立**。评分函数的能力分级是 CASF 框架的成熟常识（scoring/ranking/docking/screening 四能力分开考核）；EGARPS+ 原文（JCTC 2025）只声明了 docking power；Kappel 2019 盲测早已证明 RNA-蛋白亲和力跨序列排序是未解问题。P2 结果与文献预期完全一致，不能当"发现"卖。
- **修正后（v2）**："**agent 维护实证的自我能力模型，其规划、决策、发言全部以该模型为条件**"——agent 在战役前/战役中于锚点集上把 oracle 按 CASF 四能力实测分级，写入持久自我模型；能力等级硬约束实验规划与动作空间（DecisionGate），并逐条约束最终结论的强度（ClaimGate）；未通过画像的能力需求触发实测、降级（结论限同靶点相对比较）或拒绝。

### 1.2 空位分析（为什么这个创新点成立）

- **工具与用法都不是我们的私货**：RhoFold（Nat Methods 2022）、Protenix（AF3 级）、EGARPS+（JCTC 2025）均为已发表标准件；"结构置信度/对接分当 oracle"是领域通行做法（AF3 ipTM 被大量论文用作设计验证）。问题不是工具选错，而是**整个领域把工具用出验证边界，且没有任何系统在入口处把关**。
- **现有 agent 自我纠错文献只验证执行正确性**：PhysVEC（arXiv 2604.00149）验证代码与物理断言；Bioptic（arXiv 2602.15019）自省"没有针对最终筛选目标的 validator 就会静默失败"。**没有任何 agentic 系统维护实证的自我能力模型，并以它约束自身的规划、决策与发言**——这是没人认领的空位。人工管线里"审核 oracle 适用性"是科学家本人的职责；正因为 agent 在无人审视下大规模产出 claim，把关才必须从"科学家的良好习惯"升级为"架构原语"。
- **新颖性的诚实边界**：概念上是 CASF + ML 指导蛋白质工程中"代理模型逐战役校准"向 agentic metacognition 的迁移。新颖性在：(a) 向 agentic 系统的首次系统化迁移；(b) 四能力画像协议本身（可独立成为社区标准）；(c) "实证自我模型 + 双层门控"作为架构原语。**写论文时不得把概念本身表述为原创思想。**

### 1.3 两个辅助创新点

- **跨战役案例记忆**（CASCADE 思路落地）：每次战役的（靶点特征，画像结果，干预，预算，结果）进案例库；案例库同时是自我模型的持久化载体——新任务检索相似战役，连同其画像一起迁移（置信度降级）。可检验 claim：达到同等 best-of-pool 的评估次数随战役数下降（学习曲线）。
- **预算感知实验决策**：固定 workflow 升级为主动实验设计——每步生成量/方向/停止由预期信息增益驱动，且预算分配以能力等级为条件（无 screening power 的 oracle 不分配大规模筛选预算）。P3 证明粗粒度"诊断引导再生成"不行，换成有原则的 active learning（LLM 提假设、统计模块分预算）。

## 2. 系统架构（Layer 3 重建）

### 2.1 保留与废弃

- **保留**：Layer 0–2 全部（工具封装、能力注册、11 个领域工作流、微服务预检）、§13.1 试点规范、stats_utils、INTERFACE LOCK 机制。旧 agent 类作为**对照臂**保留在实验中（非门控基线）。
- **废弃**：CoordinatorAgent 的 BMC 协调循环作为主叙事（降级为被审计对象）；QualityAgent 的事后 LLM 评审（被门控取代——评审不增信，画像才增信）。

### 2.2 新组件

```
Layer 3（新）
├── SelfModel              实证自我模型（核心状态）：(oracle, 任务类型, 靶点族) →
│                          CASF 四能力等级 + 证据指针 + 置信度；随 CaseMemory 累积演化
├── CapabilityProfiler     能力画像器：锚点集实测 → 写入/更新 SelfModel（执行确定性，不含 LLM）
│   └── anchors/           锚点集基础设施（P2 的 15 条目为 prototype，扩展至每任务类型）
├── DecisionGate           决策门控（动作前）：实验计划与动作空间按能力等级硬约束——
│                          无 ranking power 的 oracle 禁止作候选排序目标；
│                          无 screening power 的禁止承担大规模筛选评估
├── ClaimGate              发言门控（结果写入前）：每条结论必须携带
│                          (oracle, 能力等级, 画像证据指针)；越级结论自动降级/拒绝
├── CaseMemory             案例库：战役档案（靶点特征向量、画像、干预、预算、结果、判定）
│                          + 相似度检索；同时是 SelfModel 的持久化载体
├── ExperimentPlanner      预算感知实验规划：LLM 声明本战役 claim 依赖的能力等级、
│                          提出实验假设；统计模块分配预算 + 停止规则；
│                          全部计划过 DecisionGate，消耗计入预算账本
└── AuditTrail             审计追踪：画像/双层门控/预算/SelfModel 每次更新全部落盘，
                           论文级可复现
```

组件耦合关系：SelfModel 是枢纽——CapabilityProfiler 写它，DecisionGate/ClaimGate/ExperimentPlanner 读它，CaseMemory 持久化它，AuditTrail 记录它的每次变化。删掉任一组件，其余组件的功能链都会断（与旧版"删掉画像门控 agent 照常跑"的外挂结构本质区别）。

### 2.3 一次战役的标准流程

1. **自我模型查询**：任务类型 + 靶点 → 查 SelfModel：有直接画像 → 免实测；仅有相似战役画像 → 迁移使用并降级置信度；无 → 进入画像步骤。
2. **假设声明（LLM）**：LLM 声明本战役 claim 依赖的能力等级（如"做亲和力排序 → 依赖 ranking power"），生成最小画像计划（画像什么 oracle、什么能力、用哪个锚点集）。
3. **画像（按需）**：CapabilityProfiler 在锚点集上确定性实测 → 四能力分级回写 SelfModel。
4. **规划 + 决策门控**：ExperimentPlanner 依据能力等级与相似战役记忆生成实验计划（臂、预算、停止规则、预注册指标）；DecisionGate 裁剪动作空间——越权动作（如拿无 ranking power 的 oracle 做排序目标）直接拒绝，强制替换或降级。
5. **执行 + 在线监控**：Layer 2 工作流照常跑，所有评估计预算账本；监控 oracle 分数分布与画像预期的漂移，漂移超阈 → 触发重画像（闭环）。
6. **发言门控**：结果写入前逐条过 ClaimGate——每个定量 claim 标注其依据的 oracle 能力等级与证据指针；越级自动降级（如绝对亲和力 → 同靶点相对比较 → 仅报告趋势）。
7. **归档**：战役档案 + SelfModel 更新进 CaseMemory；AuditTrail 完整落盘。

## 3. 预注册实验矩阵（§13.1 规范）

### E1：oracle 能力画像（回答：现有 oracle 到底有什么能力？）

- **假设**：现有结构 oracle（EGARPS native_probability、Protenix ipTM、RhoFold pLDDT）对 RNA-蛋白适配体无 screening power 与 ranking power，仅有 docking power。
- **设计**：CASF 四能力 × 3 oracle × ≥6 靶点锚点集（P2 的 15 条目扩展；每靶点 ≥4 binder 亲和力梯度 + ≥3 固定种子阴性 + 天然/诱饵构象对）。试点规模：先 3 靶点（Thrombin/VEGF/PDGF-BB，数据已就绪）。
- **主指标**：每能力等级的通过率；ranking 用 Spearman ρ，screening 用 AUROC，docking 用 top-1 天然构象识别率。
- **go/no-go**：若任一 oracle 在某靶点通过 screening（AUROC>0.8）→ 该 oracle-靶点组合解锁优化 claim（系统可用性证据）；若全不过 → "现有 oracle 对 RNA-蛋白无 screening power"成为论文实证发现（预期方向，P2 已暗示）。
- ** pilot n**：3 靶点 × 3 oracle；通过后再扩 6+。

### E2：已发表 claim 的画像审计（回答：不门控的代价有多大？）

- **假设**：未门控管线产出的优化类 claim，相当比例在画像协议下不成立。
- **设计**：(a) 自家历史 claim——图 4 主效应、图 7B pegaptanib 对比，逐条过画像协议复核（数据全在）；(b) 文献 claim——选取 3–5 篇用结构 oracle 做适配体/RNA 设计断言的论文，用画像协议复核其 oracle 用法。
- **主指标**：claim 存活率（通过画像复核的比例）。
- **go/no-go**：存活率 <70% → 审计故事成立（预期方向：图 4 已确定不存活）；>90% → 审计角度弱化，叙事重心移回 E3/E4。
- **注意**：文献审计措辞限"用法复核"，不点名羞辱；自家图 4 案例以 worked example 形式做主打（2026-08-04 用户决定：不做"自我撤回"修辞，但保留案例本身——它是唯一数据齐全、不得罪外部作者的真实门控案例）。

### E3：门控 agent vs 非门控 agent（回答：门控架构有没有用？）

- **假设**：在合成审计任务集上，门控 agent 的假阳性 claim 率显著低于非门控基线，且真阳性保留率不显著下降。
- **设计**：构造 ≥20 个审计任务（混合：oracle 可信的 task —— 如 GC/CAI 等确定性指标驱动的优化；oracle 不可信的 task —— 适配体亲和力优化）。两臂：旧 agent 栈（对照）vs 新栈（自我模型 + 双层门控）。盲评最终报告中的每条 claim。
- **主指标**：假阳性率（主）、真阳性保留率（次）；**决策层次级指标（v2 新增）**：决策层越权事件数——非门控臂中将无能力依据的 oracle 用作排序/筛选目标的次数（预期门控臂 = 0，由 DecisionGate 硬保证，审计追踪可验证）。
- **go/no-go**：假阳性率相对下降 ≥50% 且真阳性保留 ≥90% → GO。

### E4：跨战役记忆学习曲线（回答：记忆有没有迁移价值？有没有真实设计收益？）

- **假设**：(a) 案例记忆（含自我模型迁移）使后续战役达到同等 best-of-pool 的评估次数下降；(b)（v2 新增，2026-08-04 用户决定）预算匹配下，有记忆臂因预算配置更准（相似战役经验指导臂选择与预算分配），最终候选在**已验证指标**上优于无记忆臂。
- **设计**：20 靶点连跑（全长 mRNA 任务，执行器为**现有 FullLengthMrnaDesignWorkflow**——接头指标已升级为全长 ddG 报告指标、自动修复路径已剥离，见「依赖」条），两臂：有记忆 vs 无记忆（随机靶点顺序，3 种子组控制顺序效应）。**预算匹配铁律**：两臂总生成评估量严格相等。
- **主指标（双终点）**：(1) 效率终点——达到目标质量的累计评估次数随战役序位的回归斜率；(2) 设计收益终点（v2 新增）——预算匹配下最终候选的已验证指标对比（CAI、MFE、接头 mfe/nt、GemORNA MRL；**禁用任何未画像 oracle 作评判**，避免 P2 式循环论证）。
- **go/no-go**：效率终点——有记忆臂斜率显著为负且 20 靶点累计预算节省 ≥25%；设计收益终点——已验证指标配对 Wilcoxon 显著且 Cliff's δ ≥ 0.3。任一终点通过 → GO；双终点均不过 → 退化至 §6 退路（记忆简化为画像结果复用）。
- **依赖**：~~P1 v2（稳定性权重）须先完成~~ → ~~2026-08-04 拍板走「生成时集成」~~ → ~~2026-08-05 拍板改走 generate-and-select（方案 C）~~ → **2026-08-05 用户拍板（Phase 0 试点后）：退方案 A**——C 经 Phase 0 预注册试点 NO-GO：shuffle 修接头的 ddG 改善达标（中位 3.3–6.2 kcal/mol）、CAI 代价达标，但稳定性代价 0.0121–0.0125/nt 超阈（≤0.01），3 靶点仅 1 过（判定书 `junction_ddg_pilot_summary.json`）；与 P1 v2、P2 构成三个互证的预注册负结果——**接头修复必花稳定性，无免费午餐**，写入 Discussion「接头优化为何困难」。E4 执行器 = **现有 FullLengthMrnaDesignWorkflow**。接头指标按 Phase 0 门 1（GO：约束服从 100%、LinearFold vs Vienna r=0.945）升级为全长 ddG 报告/画像指标（落 JunctionEvaluator，替代被证伪的片段 buried 布尔），**不进 E4 终点、不设硬门槛**；BMC 接头自动修复路径一并剥离（2026-08-05 用户拍板）。集成优化器保留为已注册能力、不接入工作流；罚项改坐标系（方案 B）降为投稿后技术债。
- **边界**：设计收益终点的 claim 限"已验证指标上更优"；无湿实验通道，不得外推为亲和力/体内功能更优。

## 4. 论文骨架（工作标题与 Results 映射）

**工作标题**：*Calibrated Agency: Capability Profiling and Claim Gating for Trustworthy RNA Design Agents*

1. **Results 1｜优化 claim 的系统性悬空**：P0–P3 + E1——预算混淆与能力越界并存，现有 oracle 对 RNA-蛋白无 screening power（实证）。
2. **Results 2｜实证自我模型与双层门控架构**：系统 + 协议（方法章节主体）。
3. **Results 3｜审计**：E2——以图 4 战役为 worked example 的门控案例研究（非门控结论 vs 画像复核 vs 预算匹配对照）+ 文献用法复核。
4. **Results 4｜门控的收益**：E3——假阳性率对比 + 决策层越权事件数。
5. **Results 5｜记忆、预算效率与真实设计收益**：E4——**全矩阵 NO-GO（2026-08-07 收官）**：预算节省 74.2%（814 vs 3153 次评估）但学习曲线三种子组斜率全为正（t p=0.91）、设计收益 4 指标全 NS；跨战役记忆策略已放弃（用户决策）。此节以负结果 + 预算节省现象呈现，动机转向 E5。
6. **Results 6｜约束导航：从选择层沉入生成层**：E5 + E6——E5 S0 GO（机械化排序 τ=1.0、3 次 LLM 调用）/ S1 NO-GO（3/5 细胞失败，失败全部归因生成方法层结构性问题：λ 档位分离不足、λ 饱和、可行档覆盖）；E6（GenNav）S0/S1/S2 全 GO——S2 主终点逐 profile JCD-pass McNemar（C vs A，n=54）**p=1.86e-09、不一致对 30:0**、c_e2e_gene=1.0；辅终点未过并已披露（Wilcoxon p=1.65e-07 过、质量束不过，几乎全部归因 HER2 类零可行 λ 档靶点的 degrade 路径）。
7. **Discussion**：能力画像作为社区标准的倡议；局限（无湿实验、画像锚点集规模、egarps 外的 oracle 未全画像、HER2 类零可行档靶点仍是未解的方法学问题）。

目标期刊：**Nat Methods 直冲**（2026-08-04 用户拍板）；拒稿后依次转 Nat Commun → NAR Genomics & Bioinformatics（保底资产无需补实验）。叙事脊梁：**系统前向呈现 + 真实案例验证**——"先画像、后发言"的门控系统在真实设计战役上拦住了非门控管线会发出的越级 claim；自家图 4 战役以 worked example 形式呈现（**不做"自我撤回"修辞**，2026-08-04 用户决定）。

## 6. 风险与退路

- **E1 反向结果**（某 oracle 有 screening power）：不是坏事——系统解锁可信优化 claim，叙事转"画像解锁"而非"画像证伪"，论文照样成立。
- **E4 学习曲线平**：记忆机制简化为"画像结果复用"（免重复画像的预算节省），仍有可报告的效率故事。
- **决策层门控效果难测量**：E3 次级指标依赖审计任务集中"诱惑性误用"设计（任务描述暗示可用未画像 oracle），若任务集区分度不足，次级指标降级为定性案例，主指标（假阳性率）不受影响。
- **Nat Methods 拒稿**：核心资产（画像协议 + 审计数据 + 系统）原样适配 Nat Commun/NAR G&B，无需补实验。
