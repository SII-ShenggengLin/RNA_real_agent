## Abstract

RNA therapeutics — mRNA vaccines, small interfering RNAs, guide RNAs, antisense oligonucleotides and aptamers — are designed by chaining dozens of specialized computational tools, and this orchestration remains expert manual work. Language-model agents could automate it, but an agent that consumes predictive scores at face value and narrates its own results can fail in ways that are hard to detect. Here we present RNADesignAgent, a tool-first agent for eleven RNA design workflows in which every predictive oracle is profiled on curated anchor sets before use, every action and claim then passes deterministic gates checked against this empirical self-model, and every tool call is recorded to an append-only audit trail. On RNADesign-210, a 210-task benchmark spanning all eleven workflows, the platform completes every task with biologically valid outputs. Profiling revealed that three deployed structure oracles retained none of their presumed screening, ranking or docking power for RNA–protein aptamers (0 of 18 cells), while an expression oracle was decisively certified on measured ribosome-load anchors. Gating eliminated false-positive claims (57.9% to 0%; 38.9% to 8.3% on the two flagship task families) while preserving true ones, and budget-matched controls retired our own earlier coordination claims. Generation-layer constraint navigation (GenNav) delivered pre-registered multi-constraint design profiles where a rule-based executor failed — decisively on mRNA (McNemar P = 1.9 × 10⁻⁹) and, at equal budget, on aptamers (discordant cells 14:3, P = 0.013). Calibrated agency makes agentic science auditable.

## Introduction

RNA has become a therapeutic modality of central importance. mRNA vaccines reached billions of doses within a year of a pandemic onset; small interfering RNAs, guide RNAs, antisense oligonucleotides and aptamers hold approved indications or are in late-stage trials across metabolic, cardiovascular and infectious disease. Every one of these modalities begins with a design problem that is genuinely multi-objective: a messenger RNA must balance codon optimality against secondary-structure stability, translation-initiation context and UTR-mediated regulation; an aptamer must fold, bind and remain specific; every candidate must additionally satisfy manufacturability and safety constraints.

The field has answered with a constellation of specialized computational tools — sequence optimizers, structure predictors, expression and stability models, off-target scanners — each excellent within its remit and silent outside it. No single tool spans the pipeline. Chaining them into a coherent design campaign remains expert manual work that can take days per target, and the number of tools a designer must master keeps growing. This mismatch between tool abundance and expert bandwidth is the bottleneck we address.

Large-language-model (LLM) agents are a natural candidate to automate this orchestration, and recent systems have demonstrated agentic tool use across the sciences — in chemistry (ChemCrow, Coscientist), protein design (ProtAgents, the Virtual Lab), gene-editing experiment planning (CRISPR-GPT) and general biomedical data analysis (BioMni). None of these addresses RNA design: BioMni, the largest open biomedical tool environment, contains no RNA sequence-design capability (verified against its repository at commit 400c1f3 — the only RNA-specific tools are a ViennaRNA RNAfold wrapper and a codon-substitution utility that requires a user-supplied codon-usage table, and its CRISPR tasks select perturbation genes and retrieve precomputed guides rather than designing them), while concurrent preprints on agentic mRNA design and RNA–ligand modelling remain single-workflow and without released code. However, deploying such agents over real predictive tooling raises a problem that current systems do not address: the agent inherits every assumption of every tool it calls, and it narrates its own results in natural language. We reasoned that three recurrent failure modes follow from this structure, and that measuring them is a prerequisite for fixing them. First, **uncalibrated tool trust**: agents consume predictive scores at face value, without validating whether a given model has demonstrated power for the task, target family or molecular regime at hand. Second, **claim overreach**: because agents draft their own reports, statements can drift beyond what the underlying measurements support, and are difficult to audit after the fact. Third, **confounded improvement**: agent strategies typically also *generate more candidates*, so an apparent optimization gain may be nothing more than a larger sampling budget. None of the existing scientific agents profiles its deployed predictors before relying on them, gates its own claims against that evidence, or matches generation budgets when comparing strategies.

Here we present RNADesignAgent, a tool-first, calibrated agent for RNA design (Fig. 1). The platform wraps 41 scientific tools behind 21 local microservices and composes them into eleven deterministic domain workflows; a multi-agent execution layer orchestrates, reviews and synthesizes, and the language model never writes a sequence — every molecule is produced by a validated generator, which makes every design decision traceable to an auditable tool call. Two mechanisms then supply the calibration. **Capability-layer evidence gating (CapGate)** profiles each (oracle, task type, target family) combination on assertion-curated anchor sets before use, and feeds the resulting capability map to two deterministic gates: a DecisionGate that forbids actions whose evidentiary basis is absent, and a ClaimGate that degrades or suppresses natural-language claims exceeding the evidence. **Generation-layer constraint navigation (GenNav)** makes the agent earn its keep where a single tool cannot: delivering batches of candidates that jointly satisfy pre-registered, multi-constraint design profiles, by navigating the generator's own control space under a matched budget. Every comparative claim in this paper follows a pre-registered, budget-matched protocol.

Our contributions are:

1. **A tool-first RNA design platform with deterministic multi-agent execution and full-pipeline auditability.** Eleven domain workflows composed from 41 scientific tools exposed as 21 local microservices, with fixed generate–evaluate–score–rank pipelines, interface-locked contracts, service pre-flight, and an append-only audit trail that records every tool call — parameters, results, timings and gate decisions — making every design decision traceable and every campaign reproducible from its trail. The multi-agent layer — pipeline scheduling, per-workflow specialists, bounded coordination, advisory quality review and synthesis — is presented with the contribution of each agent measured rather than asserted: quality review is shown to be advisory (19/19 tasks succeed with and without it), the coordination loop was removed after its headline benefit was falsified under budget matching (budget-matched serial generation proved statistically indistinguishable), and mechanized ranking reduces LLM involvement to tie arbitration with perfect rank agreement (Kendall τ = 1.0).

2. **RNADesign-210, a process-aware benchmark for RNA design agents.** Two hundred and ten curated tasks spanning all eleven workflows, with deterministic success criteria, designed null models (wild-type versus random-synonymous controls) and literature anchors (vaccine-grade mRNA sequences, known aptamers, IRES panels, measured ribosome-load sets). The platform completes 210/210 tasks, and the benchmark doubles as a continuous regression suite for the system itself. All task definitions, expected outputs and null models are released with the platform.

3. **Capability-layer evidence gating (CapGate).** An anchor-set profiling protocol that grades every (oracle, task type, target family) cell into an evidence-backed capability map, feeding two deterministic gates — a DecisionGate that blocks actions lacking an evidentiary basis and a ClaimGate that downgrades claims exceeding it; the profile is the gate's evidence base. We first show that the failure modes CapGate counters are measurable defaults of the ungated system — three deployed structure oracles failed all 18 screening cells and an ungated agent issued false-positive claims at 57.9% — and then that gating eliminates false claims while preserving true ones on both flagship task families (57.9% → 0% and 38.9% → 8.3%), with selective rather than prohibitive behaviour on certified oracles. CapGate is a production default of the platform: the profiled evidence is packaged with the system, managed oracle calls are gated at the single choke point every tool invocation passes, and every gate decision joins the audit trail.

4. **Generation-layer constraint navigation (GenNav).** A feasibility-first generator-navigation strategy that delivers batches of candidates satisfying pre-registered multi-constraint profiles — the regime where an agent demonstrates value beyond a single tool's native reach. GenNav succeeds decisively where a rule-based executor fails on full-length mRNA design (McNemar P = 1.9 × 10⁻⁹, discordant 30:0), and the identical machinery, transferred to a structure-guided aptamer generator with an entirely different control geometry, wins the discordant cells 14:3 at equal budget (McNemar P = 0.013) after lattice densification and starvation-free allocation — with the advantage's regime boundary established by a pre-registered confirmatory run. The decisive aptamer protocol ships with the platform as a user-selectable mode of the aptamer workflow: deterministic (zero LLM calls), budget-capped, and audited call-by-call like every other platform action.

## Results

### Overview of the RNADesignAgent platform

RNADesignAgent is organized as seven layers (Fig. 1a). At the base (L0), each of the 41 scientific tools — wrapping 20 vendored external research codes (17 registered git submodules) — runs in its own environment behind one of 21 local HTTP microservices, so that heavyweight GPU models (RhoFold, Protenix, EGARPS, ODesign), CPU optimizers (LinearDesign, LinearFold, ViennaRNA) and alignment suites (BLAST+, Bowtie2) are invoked through uniform, versioned contracts. Tool specifications (L0), capability wrappers that validate outputs and write per-call audit records (L1), and eleven domain workflows with a fixed generate → evaluate → score → rank skeleton (L2) are all deterministic; a service manager (L3) maps each workflow's declared requirements to microservices, health-checks them and auto-starts what is missing. Session memory and workspace management (L5) and the CLI/FastAPI entry façade (L6) complete the platform (Fig. 1c).

Two design commitments distinguish it (Fig. 1a, bottom). First, the LLM never writes sequences: its roles are restricted to orchestration, review and reporting, so every molecule traces to a deterministic generator call. Second, every comparative claim follows a pre-registered, budget-matched protocol, so reported effects are attributable to mechanisms rather than to sampling effort.

The multi-agent execution layer (L4; Fig. 1b) comprises four cooperating agents whose individual contributions we measured rather than assumed. A PipelineAgent schedules multi-node pipelines deterministically. Per-workflow SpecialistAgents own strategy and retry, deciding retries solely on hard failures (empty candidate sets, tool errors); workflows with heterogeneous multi-objective candidate pools (five of eleven: full-length mRNA, aptamer, siRNA, sgRNA handle, tertiary structure) rank candidates through a shared Achievement Scalarizing Function reference-point layer (Methods) — an earlier bounded coordination loop on top of this ranking showed an apparent coordination benefit that dissolved under budget-matched controls (see below) and was removed from the system. A QualityAgent reviews outputs against per-workflow quality profiles; it is advisory by governance — with and without it, all 19 tasks of the process-aware regression suite succeed, and by construction an LLM review failure can never convert a successful run into a failed one. A SynthesisAgent drafts multi-node reports, and its headline claims pass through the ClaimGate before publication. CapGate itself runs as a platform service rather than an experiment harness: the profiling evidence is packaged with the system as a default SelfModel, and a single choke point that every tool invocation passes records each call to the audit trail and blocks managed oracle calls whose evidentiary basis is absent — so the calibrated behaviour described in this paper is the system's out-of-the-box default, not a campaign-specific wrapper. This measured accounting of the multi-agent layer is, to our knowledge, the first in the scientific-agent literature where each agent's marginal contribution is reported, including negative results.

### RNADesignAgent executes eleven RNA design workflows with biologically valid outputs

We first established that the platform's outputs are biologically meaningful across all eleven workflows, using RNADesign-210 — our 210-task benchmark together with designed null models and literature anchors (Figs. 1f and 2). All 210 tasks completed successfully. Three observations anchor biological validity (Fig. 2a–f). (1) On 20 wild-type protein targets, CDSs delivered by the platform's default design flow — LinearDesign over its λ grid plus RNARL and GEMORNA, each generator designing against its target species' codon-usage table, every candidate folded, scored and ranked end-to-end — reached a median codon adaptation index (CAI) of 0.832, exceeding wild-type sequences (median 0.729; Mann–Whitney P = 6.9 × 10⁻⁴, Cliff's δ = 0.63), which themselves exceed random synonymous sequences (median 0.674, n = 200; P = 6.8 × 10⁻⁷, δ = 0.67) — the platform reproduces the direction of natural selection on codon use and improves on it, and the wild-type-over-random ordering confirms that the CAI assay reports a biologically meaningful direction. The same delivered CDSs are simultaneously far more structurally optimized than either control (folding energy per nucleotide: designed −0.336 versus wild-type −0.051 and random −0.047; designed-versus-null P ≤ 7 × 10⁻⁸, δ = −1.0), while wild-type and random sequences remain indistinguishable on this metric (P = 0.29) — the designed sequences lead on codon adaptation and structure at once, and the CAI ordering is not a folding artifact of the nulls (Fig. 2b,c). One attribution note is in order: the designed sequences are the ranked deliverable of the platform's one-call, audited CDS workflow run in its default configuration — no objective tuning — so the CAI and structure lifts are system-level capabilities assembled from the generator pool by mechanized evaluation and ranking. (2) Inverse folding against target secondary structures recovered the exact target structure for 21 of 25 benchmarks; the four misses sit at 2, 2, 4 and 6 mismatched positions (1, 2, 3 and 1 base pairs of the 10–14 target pairs), all on combined-parameter, partition-function-mode, extreme-temperature or longest-target edge cases (Fig. 2d). (3) On an expanded literature panel of IRES elements (nine validated viral and cellular IRES 5′UTRs against 50 random human 5′UTRs, scored threshold-free in the underlying oracle's native sliding-window regime), discrimination was limited and did not reach significance (AUROC 0.673, 95% CI 0.467–0.862; Fig. 2e), and the workflow's default full-sequence path showed none (0.478, CI 0.311–0.649) — consistent with the capability profile that gates this oracle in production below its screening threshold, and a measured negative reported as such rather than tuned away. On 22 siRNA tasks, all but one design round produced candidates with zero predicted off-targets against the reference transcriptome (Fig. 2f; the two inputs that request a transcriptome scan — one BLAST, one bowtie2 — were trace-verified as executed against the human GENCODE v46 reference, one clean and one carrying the sole 3-hit result; the remaining inputs disable the scan by specification or lack a species reference, so their zeros are scan-skipped by design). End-to-end, full design campaigns complete in minutes to about an hour per target (241 timed end-to-end runs through the user form entry on the pre-warmed platform — all 210 benchmark tasks plus the 31 PA regression sessions; pooled median 2.6 min, workflow medians from 2.5 s for deterministic scoring to 6.3 min for aptamer design; 76% of runs within 5 min, 93% within 10 min, and the single run past 1 h is the GenNav navigation aptamer session at 98.6 min; Fig. 2h), and every campaign ships a complete per-tool-call audit trail: the 241-run campaign above left 10,217 audit events — 8,798 tool calls (86.2%; 40 distinct tools; 6 failures, all one session's recovered retry sequence) and 1,377 gate decisions (13.5%; reject 690, require-profiling 553, downgrade 134 across 11 oracles), with a representative three-turn full-length mRNA session showing every event class resolvable call-by-call (Fig. 2i; case studies in Table 1). An independent second regression batch on entirely fresh inputs — twelve new process-aware benchmarks spanning all eleven workflows (new viral targets, guides, aptamer and protein targets, RNA–ligand pairs, vaccine-mRNA ASO screening, authentic IRES-positive 5′UTRs and wild-type CDSs) — passed 12/12 with zero failed turns. One authored-input defect in this batch (a start sequence one nucleotide short of its target structure) was rejected deterministically at the input layer rather than silently accepted — the calibrated behaviour extending to malformed user input.

### Uncalibrated trust, claim overreach and confounded improvement are measurable defaults

Having a working platform made it tempting to treat its most sophisticated scorers as oracles for optimization. We show that this temptation is not survivable — and that it corrupts not only actions but the language in which agents report (Fig. 3a).

**Uncalibrated tool trust.** We profiled the three structure-based oracles deployed in the aptamer workflow — EGARPS native probability, Protenix ipTM and RhoFold pLDDT — on assertion-curated anchor sets spanning six protein targets (66 sequence entries with binders, negatives and affinity series; 102 docking poses across five RNA–protein complexes with known native structures). Each (oracle, target) cell was graded against pre-registered thresholds for three capabilities: screening (binder-versus-negative AUROC > 0.8), ranking (Spearman ρ ≥ 0.6 against measured Kd) and docking (native pose top-1 in ≥ 2/3 of cases). No cell passed (Fig. 3b–d). Screening power was absent in 0/18 oracle–target cells; the best cell (RhoFold pLDDT on PDGF-BB) reached AUROC = 0.8 exactly (95% CI 0.33–1.0), still below the strict threshold. No oracle approached ranking power (best ρ = 0.56). Docking failed in 0/5 cases: the native thrombin aptamer (TBA) pose ranked last of 21 candidates. An independent calibration panel gave the same verdict from the affinity side: across a four-point thrombin Kd series EGARPS correlated at ρ = 0.40, and binders scored *below* negatives on average (AUROC = 0.356) — the marketed drug pegaptanib scored ~2 × 10⁻⁶ while a 30-nt random RNA scored 0.95 and a scrambled TBA 0.99 (Fig. 3e). The scoring chain as deployed is not merely powerless but directionally inverted on this molecular family; an agent optimizing against it would be climbing anti-signal.

Profiling the *deployed* artifact, rather than trusting the publication, proved essential (Fig. 3h). The small-molecule oracle RNAsmol initially failed to reproduce its own published performance on its own held-out test splits (AUROC 0.786 and 0.410); tracing the divergence identified a preprocessing mismatch in our service wrapper — the model's case-sensitive RNA encoding (lowercase denoting modified bases) was being collapsed to uppercase. After restoring upstream-faithful preprocessing, the deployed service reproduces the official evaluation exactly (AUROC 0.974 and 0.983; the true ligand ranks 2nd of 1,601 and 7th of 265 decoys in the published case studies), while the short-aptamer panel relevant to aptamer design remains outside demonstrated power (binder-versus-random AUROC 0.722, 95% CI 0.278–1.0; versus near-cognate 0.563, CI 0.063–1.0). The boundary is real, and demonstrable from both sides: strong, exactly reproducible power inside the training distribution; none demonstrated outside it (Fig. 2g). Only profiling the deployed artifact caught the silent degradation. Under the experiment-programme reset, the full two-sided profile was re-executed zero-intervention against the frozen platform (3,545 scoring calls over the official held-out splits, both decoy case studies and the 17-pair aptamer panel; zero failures), reproducing every registered number exactly — both in-distribution AUROCs to four decimals, both decoy true-ligand ranks, and both out-of-distribution estimates with their confidence intervals.

Profiling is equally able to *certify* power where it exists, which is what makes the capability map a usable self-model rather than a list of prohibitions (Fig. 3g). The full-length mRNA workflow's expression oracle — the GEMORNA 5′UTR mean-ribosome-load (MRL) predictor — passed decisively on all three anchor families curated from a published massively parallel translation assay (706 anchors; Sample et al., GSE114002): screening AUROC 0.990–1.000 and ranking ρ 0.835–0.926 against measured MRL. The same audit classified the platform's 3′UTR stability predictor as unprofiled — no measured-stability anchor set exists — and the DecisionGate accordingly blocks any ranking action that would rely on it.

**Claim overreach.** Because agents narrate their results, overreach is the failure mode that enters through language. On a 20-task audit set of design-reporting tasks, an ungated agent — same prompts, same underlying LLM — issued false-positive claims at a rate of 57.9% (11/19 claims), with 23 recorded events of statements exceeding the scope the evidence sanctioned (Fig. 3f), for example asserting candidate superiority from an oracle with no measured ranking power.

**Confounded improvement.** The third failure mode we found in our own earlier results (Fig. 3i). RNADesignAgent's bounded coordination loop had shown an apparent main effect on the aptamer workflow (paired Wilcoxon P = 2.1 × 10⁻⁴, Cliff's δ = +0.46) — but each coordination round doubles the evaluation pool, and the headline metric was exactly the oracle that profiling had just decertified. Two pre-registered controls dissolved the effect: under budget matching (coordination versus serial execution extended to the same 16-candidate pool) the advantage fell below the pre-registered effect-size gate (δ = 0.278 < 0.3, P = 0.13); replacing the diagnostic content of coordination with a fixed resampling instruction at identical mechanics and budget added nothing (δ = 0.222, P = 0.11). A formal self-audit of our two strongest legacy claims under the four-step protocol (declare capability dependencies, re-check against profiles, control confounds, gated re-adjudication) retired both — claim survival 0/2 against a pre-registered 70% threshold (Fig. 3i). We treat budget matching as an iron rule for every comparative claim in this paper.

### Capability gating eliminates false claims while preserving true ones

The remedy for uncalibrated trust and claim overreach is CapGate: a deterministic two-layer gate fed by the capability self-model (Fig. 4a). The DecisionGate intercepts planned actions and forbids those whose evidentiary basis is absent from the self-model — for example, ranking candidates by an oracle with no measured ranking power. The ClaimGate intercepts outgoing natural-language claims and downgrades them along a scope ladder (absolute → same-target relative → trend-only → suppressed), enforcing "no claim without verification". Both gates are deterministic, and every decision is appended to an audit trail, so the agent's epistemic behaviour is itself auditable. CapGate governed every comparative campaign reported in this paper, and it is now the platform's production default: the profiling evidence is packaged with the system, managed oracle calls are gated at the tool-execution choke point, and unprofiled predictors are blocked by default pending evidence (Fig. 4g).

We evaluated CapGate under two arms with identical prompts and the same underlying LLM, with claims adjudicated blind to arm by a deterministic adjudicator. On the 20-task aptamer-chain and synthetic audit set, gating reduced the false-positive claim rate from 57.9% (11/19 claims) to 0% (0/11) while true-positive retention was 112.5% (9/8; gating also *rescued* one claim the ungated arm had buried), and decision-layer overreach events fell from 23 to zero (Fig. 4b–d) — a hard guarantee of the gates rather than a statistical outcome. The mechanism is abstention and downgrading, not silence: the gated arm still issued claims, but only within validated scope. A pilot of this experiment had initially failed because the LLM, when blocked, substituted an undeclared free proxy — a protocol lesson now encoded in the pre-registration template: gating must close all unverified claim paths. To test generality on the second flagship family, we built a 20-task mRNA-side audit set (E3-M) from real full-length design-reporting tasks — ten with exactly recomputable ground truth (CAI, folding energy, constraint satisfaction) and ten whose evidence basis the profile denies or degrades. Gating reduced the false-positive rate from 38.9% (7/18) to 8.3% (1/12) with true-positive retention of 100% (11/11) and zero gated overreach events (Fig. 4e); the one surviving false positive traces to a predicted-versus-measured MRL rank flip on the weakest certified family (ρ = 0.835), a ground-truth property both arms face symmetrically.

On certified oracles the gates are selective rather than prohibitive (Fig. 4f): ranking by the MRL oracle is permitted on the families where profiling certified it, transferred only with decayed confidence to never-profiled families of the same oracle, and blocked outright for the unprofiled 3′UTR stability predictor. The governance result closes the loop (Fig. 4h): quality review is advisory (19/19 with and without), and an LLM review failure — for example, an API outage — is recorded as audit metadata that can never convert a successful run into a failed one. Across every campaign the in-system LLM footprint stays minimal by construction — two calls per task in the gating experiments, 2.4 per gene in mRNA navigation, a single call across the decisive aptamer run (Fig. 4i).

### Generation-layer constraint navigation delivers pre-registered design profiles

Where can an agent demonstrate value beyond a single tool's native reach? Single-metric quality (CAI, folding energy) is essentially determined by the generator's settings; within that range an agent adds nothing. The defensible agent task — arrived at through a failed experiment — is *multi-constraint batch delivery*: per target, a ranked batch of candidates jointly satisfying a pre-registered constraint matrix across multiple design profiles. GenNav implements this at the generation layer (Fig. 5a): a feasibility-first adaptive probe over the generator's control lattice (LinearDesign λ settings for mRNA; ODesign length–seed–sample gears for aptamers) establishes which gears are feasible per target before budget allocation; profile-orthogonal generation axes make design profiles separable by construction; a diversity expander enforces minimum pairwise distance within batches; and an explicit degrade path handles targets with no feasible operating point.

A first attempt had placed navigation in the selection layer — filter and rank a fixed 315-candidate pool — and failed its diversity gates for reasons structural to the generation layer: admissible candidates saturated a single λ setting (insulin batch diversity 0.82% against a 2% requirement) and feasible-gear coverage collapsed on GFP until a species-matched *E. coli* codon table was supplied (pool pass 0/315 → 12/315; Fig. 5b). Sinking navigation into the generation layer fixed exactly these failures. On 18 mRNA targets under pre-registered dual endpoints, GenNav met the primary endpoint decisively: per-profile joint-criteria delivery passed for the gated navigation arm and failed for the rule-based arm in all 30 discordant pairs (McNemar P = 1.9 × 10⁻⁹, n = 54 = 18 targets × 3 profiles), with gene-level end-to-end delivery at 1.0 (Fig. 5c,d). The stricter secondary quality bundle did not pass and is disclosed rather than hidden: essentially all quality failures trace to a single target, HER2, for which the feasibility probe found no feasible λ gear and the system degraded gracefully by design. Total LLM usage was 43 calls (mean 2.4 per gene), below the pre-registered budget (Fig. 5e).

To test generality beyond codon space, we ported GenNav — unchanged in mechanism — to the aptamer workflow, where post-profiling no structure oracle may rank candidates and the generator exposes an entirely different gear geometry. The campaign arc (Fig. 5f–i) is itself a result about where navigation earns its keep. The initial transfer (E8) confirmed mechanical generality — the navigator repaired every rule-based delivery failure it met, delivered end-to-end on 9 of 10 targets against the rule arm's 7, and spent fewer candidates (mean 36 versus 48) — but the primary endpoint was not met: 26 of 30 profile pairs pass under both arms, so no advantage can be demonstrated where the static grid already suffices, the same saturation logic that retired the selection-layer campaign. Re-anchoring the constraint matrix to make delivery gear-scarce raised rule-arm failures from 3/30 to 11/30 and exposed the real boundary; three pre-registered levers then converted the boundary into an advantage at identical 48-candidate budget: a densified 17-length lattice and S1-measured priors improved discordance fourfold (9:2, P = 0.065), and a deterministic guaranteed-repair allocation — one reinforcement round for every repairable band before any band receives a second — eliminated the per-band starvation that had repeatedly cost single cells. The decisive campaign (E14; 12 targets, panel chosen by a pre-registered rule) won the discordant cells 14:3 (McNemar P = 0.0127, n = 36): the navigator delivered 26 of 36 profile cells against the static grid's 15 (72% versus 42%), completed end-to-end delivery on 6 of 12 targets against none, never violated a budget or gate, and required a single LLM call across the entire run — the guarantee rounds are deterministic. A pre-registered confirmatory run (E15) on never-paneled targets kept the discordant wins at 14 but conceded six cells (P = 0.115; pooled across campaigns 28:9, P = 0.003, heterogeneity acknowledged), empirically confirming that the navigator's advantage is regime-specific to delivery-scarce panels. Navigation earns its keep where the generation layer makes delivery hard — codon-objective trade-offs on mRNA, scarce-band allocation on aptamers — and the honest outcome outside that regime, or where no feasible operating point exists, is a declared degradation rather than a silently weaker delivery. The decisive protocol ships with the platform as a user-selectable mode of the aptamer workflow (deterministic, budget-capped, audited call-by-call).

### Pre-registered negative results delineate durable boundaries

Three boundary findings survive as scientific results in their own right (Fig. 6). First, junction repair has no free lunch (Fig. 6b): three independent pre-registered attempts to repair 5′UTR–CDS junction burial — post-hoc codon shuffling with a stability-weight sweep, a junction-penalized global-fold optimizer (a purpose-built LinearDesign patch), and a generate-and-select route against a validated full-length constrained-fold ddG metric — all failed their acceptance gates because opening junctions costs global stability. The ddG metric itself passed validation (constraint obedience 216/216; LinearFold-versus-ViennaRNA r = 0.945; Fig. 6c) and is now the platform's reporter; we regard this triple of negative results as a durable contribution to the mRNA design community. Second, cross-campaign memory does not pay (Fig. 6d): a 120-campaign trial of experience injection cut evaluation budgets by 74.2% (814 versus 3,153 evaluations) but produced no learning-curve improvement (all three seed-group slopes positive; P = 0.91) and no design-quality gain — the strategy was abandoned and the negative result registered to discourage repetition. Third, the generator boundaries themselves (Fig. 6e): ODesign produces zero candidates on a ferritin-family target class, LinearDesign has a hard memory ceiling on multi-thousand-amino-acid proteins (now fail-fast under an address-space guard), and HER2-class targets admit no feasible λ gear — exactly the kind of tool limits a calibrated agent must know before, not after, planning a campaign. Together with the capability map (Fig. 6a), the closed escape routes around the budget rule (Fig. 6g), the classified failure taxonomy of all campaigns (Fig. 6h), the per-campaign LLM usage accounting (Fig. 6i) and the aptamer scarcity boundary (Fig. 6f), these results define what the agent may not claim as firmly as the earlier sections define what it may.

### End-to-end case studies

Three end-to-end cases illustrate calibrated operation (Table 1). (A) A full-length SARS-CoV-2 Spike mRNA campaign completed in 85 minutes; the best candidate's CDS CAI (0.946) approaches the BNT162b2 anchor (0.952). (B) An anti-VEGF aptamer campaign completed in 47 minutes; its top candidate scores 0.70 on the EGARPS component where the pegaptanib anchor scores ~5 × 10⁻⁷ — a six-orders-of-magnitude gap that, post-profiling, we report *not* as a superiority claim but as the worked example of the self-audit: the oracle lacks screening power on this family, the complexes come from incomparable sources, and the anchor's 2′-fluoro modifications are unrepresentable to the scorer. (C) An NSP12 siRNA campaign with off-target scanning completed in 73 seconds, with all top-five candidates showing zero predicted off-targets. Each case ships with a complete audit trail: every tool call, parameter and intermediate metric is recorded in the session workspace.

## Discussion

In this work we showed that three failure modes of agentic science — uncalibrated tool trust, claim overreach and confounded improvement — are not theoretical risks but measurable defaults of a deployed system, and then presented RNADesignAgent, a tool-first agent built to counter them. Three findings carry the argument. First, capability profiling revoked every presumed oracle power we tested on the aptamer chain (0/18 screening cells, 0/5 docking cases) while certifying power where it genuinely exists — the expression oracle's ranking power on measured-MRL anchors, and a small-molecule oracle's published performance, reproduced exactly once a silent deployment fault was repaired. Profiling is a two-sided instrument: it tells an agent not only what it may not do, but what it may. Second, budget-matched self-audit retired our own headline claims, showing that confounded improvement is likewise a default state of agentic evaluation. Third, the remedies work: capability gating eliminated false claims while preserving true ones on both flagship task families, and generation-layer constraint navigation delivered pre-registered multi-constraint profiles with decisive significance on mRNA (McNemar P = 1.9 × 10⁻⁹) at 2.4 LLM calls per gene — and the identical machinery, re-pointed at a generator with an entirely different gear geometry, won the discordant cells 14:3 on aptamers at equal budget with a single LLM call across the run.

A central insight is that the locus of intelligence in a trustworthy agent is not the language model but the *evidence infrastructure* around it: the anchor sets, the capability grades, the gates, the audit trail. This is a principled response to how agentic systems actually fail: language is where overreach enters, so claims — not just actions — must be gated; sampling is where confounds enter, so budgets — not just outcomes — must be controlled; and deployment is where tools silently diverge from their papers, so the deployed artifact — not the publication — must be profiled. The multi-agent layer follows the same discipline: each agent's contribution is measured, and where measurement falsified a benefit — coordination, cross-campaign memory — the mechanism was demoted to what the evidence supports. We also note what calibrated agency is not. It is not autonomous discovery: the system is a scientist-in-the-loop design instrument whose deliverables are candidates, profiles and audit trails, and we emphasize the distinction between calibrated tool orchestration and genuine scientific reasoning. Nor is it a claim that the underlying oracles are weak — only that their power is regime-specific, and that the regime must be established before, not after, optimization. Finally, because RNA design touches therapeutic development, dual-use considerations apply: the platform's deterministic gates, off-target scanning and per-call audit trails are guardrails in themselves, and we release the capability map so that others can inherit the boundaries rather than rediscover them.

Several limitations mark opportunities for continued development. (1) All validation is computational; the anchors and nulls are literature-derived, and no wet-lab confirmation was performed. The profiling protocol, however, is wet-lab-ready: anchor sets accept new measurements as first-class rows, and capability grades update without code changes. (2) A single LLM backend (DeepSeek) was used for the in-system language roles. Multi-backend replication was descoped by decision: the gated roles are narrow (tie arbitration, claim drafting), the gates themselves are deterministic and model-agnostic by construction, and the result that quality review is advisory-only (19/19 with and without) bounds the backend's influence on outcomes. (3) Capability profiles currently cover the oracle families used for selection and ranking in the two flagship task families; the platform's remaining predictors carry only their literature validation until profiled, and the anchor sets, though assertion-curated and coverage-checked, remain modest in size. Under the production enforce policy this means aptamer structure-oracle components default to zero for all candidates equally — ranking then rests on the deterministic constraint matrix, which is the calibrated behaviour — but richer oracle coverage would restore more informative ranking where power genuinely exists. (4) The rule-based comparator in the navigation experiments is deliberately simple; the discordance should be read as evidence that constraint navigation is necessary, not that every alternative heuristic would fail. (5) Navigation quality bundles fail on targets with no feasible generator operating point (HER2 class); expanding the generator family or the λ lattice for such targets is the next methodological step. Overall, these represent areas for ongoing development rather than fundamental limitations.

More broadly, the artifacts released here — the capability map of widely used RNA oracles, the assertion-curated anchor sets, the budget-matched pre-registration templates, and the register of concluded directions (including the junction-repair and memory-strategy negative results) — are reusable independently of our system. Any agentic pipeline, in any domain, can adopt the same discipline: profile before you optimize, gate before you claim, match budgets before you compare. We anticipate that calibrated agency will become more, not less, important as agents grow more capable, because each added capability enlarges the space of plausible-sounding but unverified actions.

## Methods

### System architecture

RNADesignAgent is implemented as seven layers. L0 (tools): 41 scientific tools, each defined by a Pydantic-typed specification (identity, version, endpoint, capabilities, limitations) and exposed through one of 21 local FastAPI microservices, one per external code family, each with its own environment and local model weights; 20 external research codes are vendored under `external_repos/` (17 registered git submodules). L1 (capabilities): thin wrappers that validate tool outputs against their specifications and write audit records (unique per-parameter result keys, per-call timings) into the shared state. L2 (workflows): eleven domain workflows (mRNA CDS design, full-length mRNA design, mRNA sequence scoring, siRNA design, sgRNA design, ASO target screening, IRES prediction, RNA aptamer design, RNA secondary-structure design, RNA tertiary-structure design, RNA–small-molecule interaction), all subclasses of a base workflow enforcing a generate → evaluate → score → rank skeleton with progress events and partial-rerun support. L3 (service orchestration): a service manager mapping each workflow's declared `required_capabilities` to microservices, with file-locked, health-check-gated auto-start. L4 (multi-agent execution): a deterministic PipelineAgent scheduling pipeline nodes; per-workflow SpecialistAgents owning retry decisions (hard failures only); the five multi-objective workflows rank through the shared ASF reference-point layer described below (a bounded coordination loop formerly layered on top was evaluated, not credited with a coordination benefit, and removed — Results); an advisory QualityAgent issuing per-workflow quality reports (three deterministic workflows are explicitly exempt); and a SynthesisAgent for multi-node reports. L5 (session/workspace): per-session workspaces with context-propagated session IDs and cross-turn result history. L6 (entry): a form-driven CLI and FastAPI façade through a unified runner; workflow selection is explicit, and user-supplied parameters are sanitized against workflow input models.

### Multi-agent execution and governance

Each agent's role is deliberately narrow, and each claim about it is measured. The SpecialistAgent retries only on `WorkflowResult.is_hard_failure` (success = false with empty candidates or tool errors). The QualityAgent produces advisory `QualityReport`s; if the LLM review call fails, the report is marked `review_unavailable` (zero-confidence pass) with the error retained in state for audit, and an LLM-chosen abort is recorded as advice only — neither path can flip a successful run to failed (verified 19/19 on the process-aware regression suite, both arms). The former BMC coordination loop was evaluated under budget-matched and guided-versus-unguided controls, registered in the project's decision log, and removed from the implementation after its control showed statistical parity with plain serial generation. Mechanized ranking replaces LLM ranking outright in the navigation campaigns: the system enforces utility order and the LLM arbitrates ties only (Kendall τ = 1.0 versus system order at three calls per campaign).

### Candidate ranking: achievement scalarizing reference-point optimization

Every workflow whose candidate pool carries two or more heterogeneous objectives ranks through one shared implementation (`agent_core/workflows/multi_objective.py`). Objectives are min–max normalized to [0, 1] within the candidate pool, and candidates are ordered by an augmented Chebyshev achievement scalarizing function (ASF) against a reference point *r*: ASF(s) = max_i {w_i (r_i − s_i)} + ρ Σ_i |w_i (r_i − s_i)| with ρ = 10⁻³, which guarantees Pareto-optimality of the minimizer; weights are uniform by default or renormalized from a workflow's existing weight parameters. The reference point is user-supplied in raw units or, by default, the utopian point (pool-best per dimension); a non-dominated Pareto frontier on raw objective values is always returned alongside the ordering. The layer encodes three explicit missing-data policies. A dimension unmeasured across the whole pool — an oracle blocked by CapGate, or an optional evaluator disabled — drops out of the ranking for every candidate equally (the CapGate degrade semantics: components zero or vanish for all, never for some). A dimension missing for an individual candidate (a failed or skipped oracle call) is imputed at the measured pool-worst normalized value: omission from the Chebyshev maximum can only lower a candidate's ASF, so a 2026-08-20 audit replaced the earlier omission semantics — which rewarded evaluation failures — with pool-worst imputation, which additionally leaves the normalization of the measured candidates undistorted. A user reference point covering only part of the measurable dimensions restricts the ranking to that subset and is flagged in the run summary rather than applied silently. Five of the eleven workflows use this layer — full-length mRNA (CDS quality, 5′UTR ribosome load, 3′UTR stability, full-length folding energy), aptamer (complex probability, predicted fold confidence, interface score), siRNA (duplex efficiency, specificity, and a nearest-neighbour thermodynamic end asymmetry that favours antisense-strand guide loading; the full pool is ranked before truncating to the requested count), sgRNA handle (CRGPT perplexity, CRISOT specificity) and tertiary structure (predicted fold confidence plus two reference-based closeness measures, RMSD and TM-score); the remaining six are single-objective, single-candidate or domain-formula tasks where scalarization is vacuous and rank directly. ASF values are pool-relative by construction (ranks are non-monotonic under pool composition, and the utopian reference can be attained, ASF = 0); cross-pool comparisons therefore never compare raw ASF distances — they use shared fixed reference points, per-objective components or Pareto hypervolume.

### Capability-layer evidence gating (CapGate)

The SelfModel maps each (oracle, task type, target family) tuple to one of four capability grades (screening / ranking / docking / none) with evidence pointers and confidence. The CapabilityProfiler computes grades from anchor-set evaluations against pre-registered thresholds (screening AUROC > 0.8; ranking Spearman ρ ≥ 0.6; docking native top-1 in ≥ 2/3 cases), with a deterministic driver backend. The DecisionGate intercepts planned actions and forbids those whose evidentiary basis is absent; the ClaimGate intercepts outgoing claims and downgrades them along a scope ladder (absolute → same-target relative → trend-only → suppressed), enforcing "no claim without verification". Both gates are deterministic; every decision is appended to an append-only JSONL audit trail. Since the 2026-08-18 platform integration, CapGate is a production default rather than a campaign harness: a process-wide runtime (`agent_core/calibrated/runtime.py`) configured by the entry runner (environment switch `RNADA_CAPGATE` = off / advisory / enforce, default enforce) (i) records every tool call made by any workflow to the platform audit trail (name, arguments summary, success, timing, error, gate flag, and the session and workflow identity of the run that made the call, so every line of the append-only trail is attributable to its run), (ii) reviews the managed oracle tools — the aptamer structure oracles, both GEMORNA UTR predictors and the small-molecule scorer — against the SelfModel at the single tool-execution choke point, blocking calls whose grade is failed or unprofiled under enforce policy (workflows' existing fallbacks zero the affected component for all candidates equally, so runs complete and the oracle is neutralized rather than crashing), and (iii) passes the headline claims of multi-node synthesis reports through the ClaimGate, with claim extraction as the only LLM step. The profiling evidence travels with the system as a packaged default SelfModel built from the frozen E1, E7 and RNAsmol verdict files (generator `experiments/build_default_self_model.py`), so production gating enforces the published profiling results out of the box. Family transfer in the SelfModel is conservative: a never-profiled (oracle, task) family inherits the donors' worst grade per capability. Anchor sets are assertion-curated: entries carry role labels (binder, negative, unrankable), internal consistency assertions and negative assertions are checked at build time, and coverage (≥ 4 binders and ≥ 3 negatives per target) is verified before use. mRNA-side anchors follow the same pattern with measured continuous labels (mean ribosome load) substituted for affinities, dichotomized at pre-registered pool extremes (top versus bottom 60 of the read-depth-filtered pool) for the screening grade, with a 120-anchor rank-stratified subset per family for the ranking grade.

### Generation-layer constraint navigation (GenNav)

GenNav comprises four components: (1) a feasibility-first adaptive probe over the generator's gear lattice that determines which gears are feasible for a target before budget allocation, with an explicit degrade path when no gear is feasible; (2) profile-orthogonal generation axes so that design profiles are separable by construction; (3) a diversity expander enforcing a minimum pairwise edit distance within delivered batches; and (4) explicit generator-context resolution (for mRNA, species-matched codon tables; for aptamers, length and seed gears). Ranking is mechanized: the system enforces utility order and the LLM arbitrates ties only. Constraint matrices are pre-registered per campaign (mRNA matrix: GC content windows, homopolymer runs < 14 bp, initiation-region stems ≤ 12 bp, full-length stems ≤ 30 bp, boundary GC, CAI ≥ 0.8; aptamer matrix v3: per-profile length bands compact 25–34 / standard 40–55 / extended 61–80 nt, per-band GC windows and stem caps, homopolymer runs < 6 nt, and a within-batch normalized edit distance ≥ 0.15 among the five delivered candidates per profile). For mRNA, the gear lattice is the LinearDesign λ set {0, 2, 8, 20, 50} with profile-orthogonal axes (CAI-maximizing, fractional, floor); for aptamers, the lattice is the ODesign (length, seed, sample-count) grid over a densified 17-length lattice (~3 nt per band: {25, 28, 31, 34, 40, 43, 46, 49, 52, 55, 61, 64, 67, 70, 73, 76, 80}). The generation budget is identical across arms in every campaign (the budget-matching rule): on aptamers, 48 raw candidates per target per arm, the navigation arm spending at most four targeted reinforcement rounds of six candidates inside the same cap, with a deterministic guarantee rule that allocates one round to every repairable delivery band before any band receives a second. Reinforcement gears are selected from S1-measured laplace-smoothed pass rates (S1 probe: the same lattice at depth two per length); the S2 allocation fuses the S1 prior with the live pool at no extra budget. Aptamer target metadata are assertion-checked before generation: a target's declared hotspot residues are validated against the structure chain's numbering, falling back to automatic hotspot identification on mismatch. Since the 2026-08-19 platform release, the decisive aptamer protocol is a production path: the aptamer workflow's opt-in navigation mode runs the densified-lattice probe, the cycling guaranteed-repair allocation and the per-profile delivery deterministically (zero LLM calls), folds every candidate through the audited LinearFold service for the constraint matrix, caps the generation budget at 48 raw candidates, stops early once every profile is deliverable, and writes the complete navigation trace (probe, rounds, per-profile deliveries, degrades) to the run record — so a navigation campaign is reproducible from its audit trail exactly like every other platform action. On fresh targets never used in any campaign, production navigation runs delivered the full five candidates in all three constraint profiles with no degrade while exercising both allocation paths: one target exhausted the budget cap (47/48 raw candidates, five cycling guarantee rounds) and a second triggered the pre-registered early stop at 35/48 once every profile was deliverable.

### Benchmarks, anchors and experimental campaigns

Benchmarks used: a 210-task platform suite across the eleven workflows; a 20-target full-length mRNA suite (two legacy oversized targets — the ZIKV polyprotein and factor VIII, both beyond the LinearDesign memory guard — replaced by OTC, 354 aa, and PDGFB, 241 aa, with translation-verified RefSeq CDSs); a 20-target aptamer suite; and a 19-task process-aware multi-turn regression suite (also serving as CI). External anchors include BNT162b2/mRNA-1273 full-length sequences, 20 wild-type CDSs with 200 random synonymous controls, known aptamers (TBA, pegaptanib, SARS-CoV-2 N binders), an IRES positive/negative panel, small-molecule binder/non-binder pairs, RNAsmol held-out test splits and decoy case studies, and measured-MRL 5′UTR sets (Sample et al., GEO GSE114002). All comparative experiments followed the pilot-first protocol: pre-registration (hypothesis, primary metric, expected effect size, gate, pilot n recorded in the driver), a small-scale pilot with a decisive control arm, a go/no-go gate, and disciplined recording of negative pilots as evidence. The budget-matching rule — equal total generated-and-evaluated candidates across arms for any best-of-pool or hypervolume comparison — was enforced in P0, P3, E4, E6 and E8–E15. The E3-M mRNA audit set mirrors the E3 construction on real mRNA assets: ten trusted-deterministic tasks whose ground truth is computed by exact recomputation (CAI via Sharp–Li weights on the built-in Homo sapiens Kazusa table; folding energy via LinearFold; constraint satisfaction) and ten untrusted-oracle tasks whose decoy scores are real platform outputs (GEMORNA 3′UTR stability and MRL on never-profiled families; junction metric). The gated arm's SelfModel is preloaded from the E7 profile, with deterministic report metrics registered per task family; both arms make exactly two LLM calls per task at temperature 0. The complete campaign-level evidence trail (pre-registrations, verdict files, adjudication materials, failure taxonomy) is bundled in `experiments/results/` and indexed in `docs/PAPER_FACT_SHEET.md`.

### Statistics

Paired comparisons used two-sided Wilcoxon signed-rank tests with Cliff's δ as effect size; multiple-testing control used Benjamini–Hochberg FDR. AUROC confidence intervals used 10,000-fold bootstrap. The GenNav primary endpoints used paired McNemar tests on per-profile joint-criteria pass/fail (mRNA: n = 54 pairs; aptamer: n = 30 pairs in the initial transfer, n = 36 pairs = 12 targets × 3 profiles in the decisive campaign). Oracle ranking grades used Spearman correlation against measured values (Kd or MRL). The memory learning-curve endpoint used a one-sided one-sample t-test on per-seed-group slopes. Thresholds were pre-registered per campaign (for example, δ ≥ 0.3 for pilot GO gates; AUROC > 0.8; ρ ≥ 0.6; FDR q < 0.05 with |δ| ≥ 0.3 for design gains).

### LLM usage and cost reporting

The sole external LLM in all reported results is DeepSeek (deepseek-v4-pro; official endpoint; temperature 0.2 for legacy quality reviews, 0.0 for the in-system LLM under test). Measured usages: platform quality-review suite 93 calls (414,088 prompt + 194,261 completion tokens); gating experiments 80 calls (E3) and two calls per task (E3-M); memory campaign 230 calls; mRNA navigation campaigns 3 (S0), 23 (S1) and 43 (S2) calls; aptamer navigation campaigns 76 calls total across E8 (mean 4.6 per target at S2) and a single LLM call across the 12-target E14 decisive run (deterministic guarantee allocation); oracle profiling campaigns use no LLM calls. All structure and sequence models run as local microservices with local weights. Experiment orchestration was assisted by a coding agent external to the tested system.
