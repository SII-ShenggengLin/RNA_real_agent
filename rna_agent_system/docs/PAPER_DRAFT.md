## Abstract

Computational RNA design still requires experienced biologists to chain many specialized tools. Language model agents promise to automate this process, but face three issues: adopting predictor scores as optimization objectives without validating them on the design task, asserting claims beyond what their evidence supports and reporting gains confounded by unequal sampling budgets. Here we present RNADesignAgent, a multi-agent system for RNA design that addresses these issues through capability-layer evidence gating and generation-layer constraint navigation. Capability gating evaluates every predictor on verified anchor sets before use and prevents unsupported actions and claims. Constraint navigation guides generators to produce candidates satisfying multi-constraint requirements. Capability gating removed false-positive claims across 45 aptamer tasks (0% versus 54.5% ungated) while preserving most true ones, and constraint navigation improved constraint satisfaction at equal budget across 25 messenger RNA targets (exact McNemar P = 0.009). RNADesignAgent produces high-quality RNA molecules and offers design principles for future scientific agents.

## Introduction

RNA therapeutics deliver RNA molecules that encode therapeutic proteins, silence or edit disease-causing genes, or bind disease-causing proteins. Messenger RNAs (mRNAs), small interfering RNAs (siRNAs), guide RNAs, antisense oligonucleotides (ASOs) and aptamers are approved medicines or late-stage clinical candidates across metabolic, cardiovascular and infectious diseases. Designing an RNA molecule with the desired properties is the critical first step in developing these therapies. Experienced computational biologists can accelerate this step and reduce experimental cost by chaining multiple computational tools. However, as the number of computational tools grows and their updates accelerate, even these specialists struggle to master the latest RNA design tools in time. This mismatch between the rapid growth of RNA design tools and the capacity of experts to master them has become a bottleneck in the high-quality computational design of RNA molecules.

Large language model (LLM) agents are a promising candidate for this automation, and recent systems have demonstrated agentic tool use in chemistry, protein design, gene-editing experiment planning and biomedical data analysis, but none of these systems covers RNA design. In addition, current scientific agents call tools without validation and report their own results in natural language, and our experiments show that this architecture produces three systematic failure modes. Uncalibrated tool trust occurs when an agent uses a tool's predictive scores without validating whether those predictions have demonstrated power on the specific task. Claim overreach occurs because agents write reports, which often contain statements that exceed what the underlying tools support. Confounded improvement occurs when an agent simply generates more candidates, so that an apparent gain may reflect a larger sampling budget rather than real improvement.

To address these failure modes, we present RNADesignAgent, a multi-agent system for automating RNA design (Fig. 1). The platform integrates 41 scientific tools through 21 local microservices and composes them into eleven domain workflows that cover the design of diverse RNA types. Capability-layer evidence gating (CapGate) evaluates every predictor on verified anchor sets, producing a capability map that drives two deterministic gates. A DecisionGate prevents unsupported actions, and a ClaimGate weakens or removes natural-language claims that exceed the evidence. Generation-layer constraint navigation (GenNav) guides the generator through its control settings to produce candidates that satisfy multi-constraint requirements at a budget matched to the comparison.

On RNADesign-210, a 210-task benchmark covering all eleven workflows, the platform completed every task with biologically valid outputs. For example, designed coding sequences reached a median codon adaptation index (CAI) of 0.896, exceeding the wild-type median of 0.729 (P = 1.1 × 10⁻⁶). Capability profiling decertified all three deployed structure predictors on aptamer tasks but certified an expression predictor on measured ribosome-load anchors. On aptamer and full-length mRNA tasks, the resulting gates reduced false-positive claims to 0% and 7.7% from 54.5% and 33.3% ungated. On 25 mRNA targets, constraint navigation at equal budget won the paired comparison against the static executor (20:6, McNemar P = 0.009). Transferred to the aptamer generator, the same mechanism won at low budgets (10:2, P = 0.039).

## Results

### Overview of the RNADesignAgent system

RNADesignAgent automates the design of diverse RNA types through a seven-layer architecture (Fig. 1a). The user states a design goal in natural language and receives designed candidate RNA molecules with their evaluation reports and a traceable record of the design process. The base layer (L0) exposes 41 scientific tools through 21 local microservices, so every tool is called through a uniform, versioned interface. The capability layer (L1) validates tool outputs and writes per-call audit records. The eleven domain workflows (L2) share a fixed generate → evaluate → score → rank skeleton, and each addresses the design or evaluation of one RNA type. The service manager (L3) matches each workflow's declared requirements to microservices, health-checks them and starts whatever is missing. The multi-agent execution layer (L4) orchestrates, reviews and synthesizes workflow runs. Session memory and workspace management (L5) isolate each session's workspace and carry its result history across turns. The entry layer (L6), a form-driven interface, receives the user's natural-language design goal and returns the results (Fig. 1a). RNADesignAgent is built on the principle that the user must be able to reproduce and inspect the design process. Every design step is therefore executed by deterministic tools and recorded to the audit trail. The complete record of every task is returned to the user, who can trace which tools were called, with what parameters and under which gate decisions, and replay the process.

The multi-agent execution layer (L4; Fig. 1b) comprises four cooperating agents. A PipelineAgent schedules multi-node pipelines, and per-workflow SpecialistAgents decide how to run the workflow and when to retry. A QualityAgent reviews outputs against per-workflow quality benchmarks, and a SynthesisAgent drafts multi-node reports whose claims pass through the ClaimGate before release.

Two mechanisms counter the three failure modes. CapGate (Fig. 1c) profiles each deployed predictor on verified anchor sets before use and enforces the resulting capability map at two deterministic gates. A DecisionGate guards the single tool-execution choke point through which every Layer-1 capability call passes, blocking unsupported predictor uses. A ClaimGate checks the SynthesisAgent's outgoing reports at Layer 4, downgrading or suppressing claims that exceed the evidence. GenNav (Fig. 1d) is a deterministic mode inside the Layer-2 workflows, implemented as a λ-curve navigator in mRNA coding sequence (CDS) design and a length–seed–sample navigator in RNA aptamer design. It delivers candidate batches that satisfy pre-registered multi-constraint profiles under a budget matched to the static executor.

### RNADesignAgent generates biologically valid RNA molecules

We tested the biological validity of the platform's outputs on RNADesign-210, the 210-task benchmark spanning all eleven workflows (Supplementary Tables S2 and S3). Every task completed successfully (210/210; Fig. 2a), with the evidence for four workflows in Fig. 2b–f and for the remaining seven in the Supplementary Information. On 20 wild-type protein targets, the delivered CDSs reached a median CAI of 0.896, above the wild-type sequences (0.729; Mann–Whitney P = 1.1 × 10⁻⁶, Cliff's δ = 0.91). The wild-type sequences exceeded random synonymous sequences (0.675, n = 200; P = 6.8 × 10⁻⁷, δ = 0.67), so the platform reproduces and improves on the direction of natural selection on codon usage. The same delivered CDSs were substantially more structured than the two controls (folding energy per nucleotide −0.297 versus −0.051 and −0.047; P ≤ 6.8 × 10⁻⁸, δ = −1.0 for both comparisons). Designed sequences therefore lead in codon adaptation and stability simultaneously (Fig. 2b,c).

Inverse folding reproduced the exact target secondary structure in 21 of 25 benchmarks (Fig. 2d). The four misses were near-exact, each differing from its target by one to three base pairs, and no candidate in the ranked set exactly reproduced any missed target, so the shortfall lies in the generation tool rather than the platform's ranking. On 22 siRNA design tasks, 21 delivered a best-ranked candidate with zero predicted off-targets (Fig. 2e). The only exception is due to the benchmark input rather than the scanner. Its synthetic target is an exact fragment of the human long non-coding RNA locus DDX11L2, so the three predicted hits are the guide's own locus and its two identical paralogous copies in DDX11L16, true genomic occurrences rather than false partial matches.

The small-molecule binding predictor matched its capability profile exactly (Fig. 2f). Through the deployed service it reproduces its published evaluations exactly, with an area under the receiver operating characteristic curve (AUROC) of 0.974 and 0.983 on the ROBIN and Protein Data Bank (PDB) test sets (95% confidence interval (CI) 0.968–0.980 and 0.961–0.997; n = 1,492 and 170 pairs), but shows no reliable power on short aptamers outside the training distribution (0.722 and 0.563 against random and near-cognate controls, both intervals spanning chance). The corresponding evidence for the remaining seven workflows is reported in Supplementary Notes 1 and 2 (§S2.1–S2.6; Supplementary Figs. S1, S3 and S4).

Every run produces a complete audit trail, with one record per tool call. The 241 production runs, covering all 210 benchmark tasks plus 31 regression sessions entered through the user form, left 24,897 audit events. Of these, 19,848 were tool calls; 4,862 were gate decisions; and 187 were assemblies of ranking objectives. Fig. 2g traces every event class call-by-call in a representative full-length mRNA session from the same trail (1,853 tool calls, 882 gate decisions and 3 ranking assemblies). A full design run completes in minutes to roughly an hour. Across the same 241 runs, the pooled median runtime was 2.5 min, with 239 of 241 finishing within 1 h (Fig. 2h).

### Current scientific agents exhibit three systematic failure modes

Current scientific agents optimize predictor scores without validating the predictor's power, report their own results without verification, and evaluate improvements under unequal sampling budgets. These practices produce three systematic failure modes, which we quantify on the platform itself (Fig. 3). Uncalibrated trust corrupts the agent's actions, claim overreach corrupts its reports, and confounded improvement corrupts its own evaluation.

The RNA aptamer design workflow ranks candidates by the scores of three structure-based predictors, EGARPS+ native probability, ProteinX interface confidence (ipTM) and RhoFold mean per-residue confidence (pLDDT). To quantify uncalibrated tool trust, we profiled all three on verified anchor sets. The affinity set holds 95 sequence entries spanning nine protein targets (67 binders, 62 of them with a measured dissociation constant (Kd), and 28 negatives). The docking set holds 19 solved RNA–protein complexes across 14 independent protein targets. Each predictor–target combination was graded by pre-registered thresholds for screening (AUROC above 0.8), ranking (Spearman ρ at least 0.6) and docking (native pose top-1).

None of the three showed reliable power in any capability. For screening, only 2 of the 27 predictor–target combinations pass the gate, ProteinX on swine H3 HA and EGARPS on IFN-γ, but all 27 confidence intervals span chance (Fig. 3a). FGF2, with the widest Kd range, stays sub-gate for all three predictors. For ranking, 4 of 27 combinations reach ρ ≥ 0.6, all three predictors on the IFN-γ series (ρ = 0.71, 0.66 and 0.60, n = 6) and ProteinX on Angiopoietin-2 (ρ = 1.0, n = 3) (Fig. 3b). The three IFN-γ intervals span zero, and that series is a single in-silico-mutant family spanning under one order of magnitude of Kd, while the Angiopoietin-2 estimate rests on three points whose scores flip between ~0 and ~1 across stochastic complex realizations. For docking, the native pose ranked top-1 in 0 of 19 complexes, falling at ranks 6–20 of 21 candidates (Fig. 3c). The Kd analysis also gave the same conclusion (Fig. 3d). The thrombin Kd series (n = 6) reached ρ = 0.49, below the ranking gate, and the predictor did not separate binders from negatives better than chance. The three predictors are therefore not reliable optimization objectives, and an agent that optimizes these scores may raise them without obtaining a better RNA molecule.

The second failure mode, claim overreach, occurs because agents report their own results without verification (Fig. 3e). We ran an ungated agent on a 45-task audit set of design-reporting tasks. It made false-positive claims at a rate of 54.5% (30 of 55 claims, 95% CI 41.5–67.0%), and its plans or statements exceeded what the evidence supported 59 times, at 8–11 events per predictor–use combination (ranking or screening). The failure occurs only where the evidence is untrusted. The 24 trusted-deterministic tasks produced 23 claims, every one verified true by exact recomputation. The 21 untrusted-predictor tasks were scored by the three predictors profiled above and produced 32 claims, 30 of them false. The agent declares the predictor's top scorer the best binder, and the held-out Kd ground truth shows otherwise. The failure is not caused by the task construction either, because the original and rule-extended tasks fail at the same false-positive rate (55.6% versus 53.6%).

The third failure mode, confounded improvement, emerged in the platform's earlier results (Fig. 3f). RNADesignAgent's earlier coordination loop was run across the full aptamer benchmark. We compared it against a single-run baseline, the same run given the loop's budget, and a fixed-resampling control that replaces its between-round analysis with content-free regeneration. On the uncalibrated EGARPS-component metric, the loop showed an apparent advantage (Cliff's δ = +0.14), because each coordination round doubles the evaluated pool. The advantage falls to δ = +0.05 at the loop's budget and disappears (δ = −0.01) in the fixed-resampling control. Confounded improvement is not specific to this loop, but a general risk whenever improvements are evaluated under unequal sampling budgets. We therefore enforce budget matching on every comparison in this paper.

### Capability gating eliminates false claims while preserving true ones

The remedy for uncalibrated trust and claim overreach is CapGate, a deterministic two-layer gate fed by the capability self-model (Fig. 1c). The DecisionGate intercepts planned actions and forbids those whose evidentiary basis is absent from the self-model, for example ranking candidates by a predictor with no measured ranking power. The ClaimGate intercepts outgoing natural-language claims and downgrades them along a scope ladder (absolute → same-target relative → trend-only → suppressed), enforcing "no claim without verification". Both gates are deterministic, and every decision is appended to an audit trail, so the agent's claims and decisions are themselves auditable. CapGate is the platform's production default rather than a campaign harness, and it governed every comparative campaign reported in this paper. The profiling evidence ships with the system as its default self-model. Every call to a governed predictor passes through the platform's single tool-execution entry point, where it is checked against that self-model before the underlying service is invoked; an unevidenced call is therefore rejected before it executes rather than flagged afterwards, and predictors without profiling evidence stay blocked by default until evidence exists.

The gates are only as good as the evidence beneath them, and that evidence is produced by capability profiling. Before a predictor is trusted anywhere in the system, each predictor–task–target-family combination is measured against a curated ground-truth anchor set under pre-registered thresholds, and the resulting grades form the capability map the gates consult. Two properties of this evidence layer matter. The first is two-sidedness. Profiling withholds power that measurement does not support, but it equally *certifies* power where it exists, which is what makes the capability map a usable self-model rather than a list of prohibitions (Fig. 4a). The full-length mRNA workflow's expression predictor, the GEMORNA 5′UTR mean ribosome load (MRL) predictor, passed decisively on all three anchor families curated from a published massively parallel translation assay (706 anchors). The random 50-nucleotide family lies inside the predictor's training distribution and serves as the registered positive control; the two varying-length families carry the generalization evidence. Screening AUROC reached 0.990, 1.000 and 1.000 across the three families with bootstrap intervals clearing the 0.8 gate, and ranking ρ reached 0.926, 0.920 and 0.835 against measured MRL with intervals (0.75–0.95) entirely above the 0.6 gate, all 706 of 706 anchors scored zero-intervention through the production tool path with the predictor deterministic end-to-end through the deployed chain. The same audit classified the platform's 3′ untranslated region (3′UTR) stability predictor as unprofiled, because no measured-stability anchor set exists, and the DecisionGate accordingly blocks any ranking action that would rely on it.

These grades translate directly into the gates' per-request verdicts, which we re-measured as a twelve-cell decision matrix on the two GEMORNA expression predictors through the production runtime (enforce policy, packaged self-model, every decision audited, zero LLM calls; Fig. 4b). Ranking by the MRL predictor is allowed on all three families that profiling certified (confidence 1.0). The same request on a never-profiled family of the same predictor is downgraded rather than blocked, the self-model transferring the donor family's grade at confidence decayed to exactly 0.5 while the claim gate rewrites an absolute expression claim to within-target relative scope. Ranking by the 3′UTR-stability predictor is blocked outright. The verdicts are the tool layer's actual behaviour, verified live. Allowed and downgraded requests execute against the deployed service, the certified-family prediction reproducing the profiling cache exactly (MRL 6.28), while blocked requests fail as gate errors before any service call. All twelve cells met their pre-registered expectations, and on certified predictors the gates are thus selective rather than prohibitive.

The other property is that profiling must target the *deployed* artifact rather than trust the publication (Fig. 4c). Together with the certified grades above, this is what the gates stand on, measurements of the system as shipped rather than of what the papers report. The small-molecule predictor RNAsmol had initially failed to reproduce its own published performance on its own held-out test splits, a degradation with no error signal that only deployed-artifact profiling caught. Recovered byte-verbatim from version control and re-measured in an isolated sandbox on the same 1,662 official pairs, the pre-fix service scores AUROC 0.790 and 0.420 on the two splits (n = 1,492 and 170), agreeing with the registered incident record within 0.0094. Comparing the port's preprocessing against its pinned upstream commit revealed two deviations. One is a case collapse, in which the model's case-sensitive RNA encoding, where lowercase denotes modified bases, was upper-cased. The other is subtler. Upstream fills the molecular-graph adjacency matrix by iterating only the first two entries of the directed edge list, with every index written shifted by one, so the adjacency the shipped checkpoints were trained on was almost entirely zero with two misplaced entries rather than the molecular connectivity; the port had corrected this quirk into the intended full symmetric adjacency, silently changing the input distribution the checkpoints were trained under. After the preprocessing repair, both shipped integration paths were verified live and zero-intervention on the same pairs. The default agent tool path (wrapper uppercase plus T→U normalization, verified applied on every pair) reaches 0.975 and 0.986, and the verbatim service endpoint 0.974 and 0.983, the latter bit-identical to the registered evidence. The three measurements together also locate the damage. Case collapse perturbs individual scores substantially (PDB split median |Δp| = 0.08, maximum 0.91) yet leaves in-distribution discrimination intact, so the predictor's collapse lived in the adjacency rewrite, not in case information. The deviation that looked obviously fatal was harmless, and the deviation that looked like an improvement destroyed the predictor. Deployment infidelity is real, silent and layer-dependent, and which layer carries it is an empirical question that only measurement of the deployed artifact answers.

We evaluated the gates themselves in paired two-condition experiments on two task families, with identical prompts, the same underlying LLM, predictor scores fetched live from the deployed services and claims adjudicated blind to condition by a deterministic adjudicator. The aptamer family is a 45-task audit set with 24 trusted-deterministic tasks of exactly recomputable ground truth and 21 untrusted-predictor ranking and screening tasks spanning the nine-target anchor set; the mRNA family is a 20-task set built from real full-length design-reporting tasks. On the aptamer set, gating reduced the false-positive claim rate from 54.5% (30/55; 95% CI 41.5–67.0%) to exactly zero (0/20; CI 0–16.1%). This is a hard guarantee of the gates rather than a statistical outcome, and it held on every task (Fig. 4d). The per-claim adjudication shows where the claims went (Fig. 4e). Thirty-one claims reached the claim gate, of which 24 were published (20 adjudicated true and 4 borderline trend statements) and 7 were suppressed, with two further candidate sequences abstained by the execution-verification leg before publication. The gated condition carries no false claim on any task, and every claim that would have rested on an unprofiled structural predictor was blocked at the plan layer, downgraded to a borderline trend statement or suppressed. Decision-layer overreach events fell from 59 to zero (Fig. 4f). The decision gate blocked all 71 plan requests, every declared ranking, screening or docking use of the three decertified structural predictors plus every deterministic-proxy and hallucinated-predictor request, so the gated agent never even fetched the evidence it could not support.

The cost of the guarantee is equally measurable. True-positive retention was 80.0% (25 → 20), below our pre-registered 90% gate, and we report it as measured. The losses decompose deterministically. Two true metric claims were suppressed by the uniform basis rule, under which the model declared the deterministic metric itself as an evidentiary dependency and it gated as unprofiled; this is over-conservative, and a real cost of closing the free-proxy back door. Two length-sloppy final sequences (59 nucleotides rather than the intended 60) were abstained by the execution-verification leg, and their claims would have been false had they been published, on tasks where the ungated condition had emitted correct-length sequences. Two lucky untrusted-predictor true positives could not be retained by design, because no structural predictor holds verified ranking or screening power, and one true positive was rescued on a task where the ungated condition had made no true claim. A pilot of this experiment had initially failed because the model, when blocked, substituted an undeclared free proxy. That protocol lesson is now encoded in the pre-registration template. Gating must close every unverified claim path.

The result replicates on the mRNA set (Fig. 4g). The 20-task mRNA audit set was built from real full-length design-reporting tasks, ten with exactly recomputable ground truth (codon adaptation, folding energy, constraint satisfaction) and ten whose evidentiary basis the capability profile denies or degrades, and both conditions ran under the same blind-adjudicated protocol through the current production assets, that is, platform-default GenNav CDS deliveries, two-step full-length workflow constructs, the live predictor chain and measured-MRL ground truth from the certified anchor set. Gating reduced the false-positive rate from 33.3% (6/18; 95% CI 16.3–56.3%) to 7.7% (1/13; CI 1.4–33.3%), a 76.9% relative reduction, with decision-layer overreach falling from 5 to 0 and true-positive retention at 12/12 = 100%, so both pre-registered go gates (at least 50% false-positive reduction and at least 90% true-positive retention) pass on this family. The retention contrast with the aptamer side is itself a governance effect. The two-step workflow no longer ranks on the unprofiled 3′UTR predictor, which was demoted to a report-only diagnostic, so the never-profiled-family expression claims that previously left the true-positive count through relative-scope rewrites no longer arise, and the three cross-family claims in this task set adjudicate neutral in both conditions. The protection also operates one layer earlier than on the aptamer side. Five decision-gate blocks, on 3′UTR-stability and junction metrics declared as ranking objectives by the task prompts, left the model with no evidentiary path, and it published no claim at all on those tasks rather than fabricating one, with one further 3′UTR claim suppressed at the claim gate. The one surviving false positive traces to a predicted-versus-measured MRL rank flip on the weakest certified family (ρ = 0.835), a ground-truth property of the certified predictor itself that both conditions face symmetrically.

The same gate semantics operate at production scale (Fig. 4h). In the frozen audit slice of the 241-run production campaign, the decision gate issued 4,862 verdicts across eleven predictors, every one traceable. The 1,800 rejects concentrate on the decertified predictors (RNASTOP stability 1,271, RhoFold pLDDT 302, ProteinX ipTM 101, EGARPS 66, IRESfinder 24, GerNA-Bind 22 and RNAsmol 14); the 489 require-profiling verdicts are dominated by the never-profiled CRGPT, RNASTOP, RhoFold, CRISOT and 3′UTR-stability predictors (244, 100, 96, 25 and 24); and the 1,391 downgrades all fall on the certified MRL predictor, whose grade transfers to unprofiled families with decayed confidence. The 1,182 allows form the campaign's only allow class, every one an annotation call to the demoted 3′UTR-stability predictor permitted now that it reports but never ranks, and no ranking request was allowed, consistent with no predictor holding a verified ranking grade for the campaign's production task keys.

The platform's own governance layers are held to the same standard, measured rather than asserted (Fig. 4i). Across the full 31-session process-aware suite, every session completes and succeeds at the workflow level in all three conditions, with LLM quality review off, on, or on with the review endpoint failed, and every session's per-turn outcome is identical across conditions. The only retry in the matrix is a single on-condition turn that hard-failed after its first review call and recovered on re-run (0/1/0 retries by condition). The review-on condition completes exactly two advisory calls per reviewed turn (145 calls over 72 reviewed turns, the retried turn carrying one extra call from its failed first attempt, and the deterministic-exempt turns making none), and in the outage condition all 144 attempted calls fail into review-unavailable markers recorded as audit metadata without affecting any turn. The in-system LLM footprint stays minimal by construction (Fig. 4j), with exactly two calls per task and condition in the three gating studies (90, 90 and 80 calls), zero in the selective-gating decision matrix, zero across the three re-run navigation campaigns (both conditions deterministic), a measured mean of 2.0 review calls per run across the production campaign (483 over 241 runs), 0, 145 and 0 completed calls across the advisory experiment's three conditions, and 22 further advisory review calls in the production-entry navigation runs over 11 sessions.

The layer's agents are themselves held to the same standard in a per-agent ablation whose two-block protocol is registered in the Supplementary Methods. Across the same 31-session suite, in the production default, advisory-review-off and retry-disabled conditions, every session succeeded (31/31 per condition) with every per-turn outcome identical across conditions. The review made exactly two calls per reviewed turn (146 across the suite, the two retry rounds included) and changed no outcome; the retry mechanism rescued the two hard-failure turns it met, stochastic service hiccups whose fresh runs in the ablated conditions did not recur; and the review-disabled and retry-disabled conditions made zero and 72 calls respectively, one final review per reviewed turn. On two pre-registered two-node pipelines the same ablation reaches the two remaining agents. Executing the nodes sequentially with no agent at all produced identical node outcomes, the scheduler being behaviourally transparent on valid plans, and the synthesis agent's LLM report was the only claim-bearing artefact. Twelve claims were drafted across the two probes, of which the ClaimGate rejected five, each resting on never-profiled predictor dependencies (the two small-molecule predictors' screening scores), while the deterministic-report mode drafted none.

### Generation-layer constraint navigation efficiently generates RNA molecules that meet the design requirements

Single-metric quality (codon adaptation, folding energy) is essentially fixed by the generator's settings, and within that range an agent adds nothing. The defensible agent task, which we arrived at through a failed experiment, is multi-constraint batch delivery. Per target, the platform must deliver a ranked batch of five candidates jointly satisfying a pre-registered constraint matrix of quantitative acceptance bands on codon adaptation, GC windows, homopolymer length and structure, under each of several design profiles in turn, with expression-, stability- and balance-oriented profiles for mRNA and three sequence-length classes for aptamers. GenNav implements this task at the generation layer (Fig. 1d). The generators expose discrete settings, for mRNA the LinearDesign balance parameter λ, which trades codon optimality against folding stability, and for aptamers the length, random seed and sample count of the diffusion generator. GenNav first spends a few trial designs establishing which of these settings can meet the constraints for the target at hand, and only then commits the campaign's quota of generation calls, the number of generator invocations each strategy may spend, held equal between comparison conditions. Delivery is profile-specific, so the alternatives a user receives are separable by construction. Any two candidates in a delivered batch differ in at least a minimum fraction of positions, a sequence-diversity floor that prevents near-duplicate designs, and a target for which no setting proves feasible is reported as infeasible with its failure reason rather than silently dropped.

A first attempt placed navigation in the selection layer, generating one large fixed collection of molecules and then filtering and ranking it, at 315 full-length constructs per target (35 coding sequences × 9 UTR combinations). It fails for reasons structural to the generation layer (Fig. 5a). Across the five registered targets, the number of constructs passing all constraints ranged from 306 of 315 (EPO) and 297 (IL-2) through 144 (insulin) and 27 (A1AT) to zero (GFP), with the sliding-window GC rule the dominant binding constraint, a factor of eleven separating the best and worst non-zero targets and a complete collapse on GFP. GFP's pool stays at zero until a species-matched *E. coli* codon table is supplied (0/315 → 18/315, the passing candidates confined to the two most stability-weighted λ settings), so no selection-layer ranking can recover candidates the generator never produced. The batches that do assemble also saturate a single generator setting, with insulin's five delivered candidates differing pairwise by as little as 1.01% of positions, below the 2% diversity floor. The shipped answer is the deterministic GenNav-λ mode of the mRNA workflow, which navigates inside the generation layer. A probe sweeps a λ-curve across 35 preset values, with guaranteed repair and interstitial reinforcement, under a quota of generator calls matched to the static recipe's spend of 35 calls (4 LinearDesign λ values, 1 RNARL run and 30 GEMORNA samples); every constraint dimension carries its registered acceptance band (CAI ≥ 0.80, CDS-level stems ≤ 30 bp, the sliding-GC window, homopolymer < 14); and a synonymous-diversity step, local codon substitutions that cost no generation calls, breaks the near-identical structure of same-λ designs so that delivered batches can meet the diversity floor. Each target is designed under all three profiles, giving one paired cell per target, profile and condition, and the static condition spends its identical 35 calls on the fixed recipe.

Across 25 targets, the 20-target pre-registered suite plus five therapeutic proteins (PTH, leptin, G-CSF, thrombopoietin and PLAT) that entered through the production user-form entry with their static conditions completed under the identical budget-matched protocol, the paired discordance test favours navigation. Twenty of the 26 cells delivered by exactly one condition go to navigation (exact McNemar P = 0.009, n = 75; Fig. 5b,c; the deployment cohort alone contributes 3:0), the joint delivery criteria (JCD) clear on 46 of 75 cells against the static condition's 32, and 22 of 25 targets receive JCD-passing delivery, nine of them at 3/3 profiles, among them HER2, on which the static pool structurally cannot deliver. Navigation spends well under its quota, at a mean 23.1 of 35 with fifteen targets stopping early at 11–28 calls (the five deployment campaigns at a mean of 17.2), ten running to the cap, and zero violations and zero LLM calls throughout. Two pre-registered disclosures accompany the win (Fig. 5d). The stricter gene-level criterion, one target delivering passing batches in all three profiles, gated at ≥ 0.8 as a legacy-era calibration, is met on 12 of 25 targets (0.48, against the static pool's 1.00 as delivery context), and with the constraint-rate criterion met (0.96 against its ≥ 0.9 gate) the two conditions' composite quality scores are statistically indistinguishable (+29/=26/−20 signed cells across the 75 pairs, Wilcoxon P = 0.73), so navigation matches the static recipe's per-cell quality while delivering more cells. GFP remains the honest boundary in the other direction, contributing three of the six static-favouring discordant cells, because its *E. coli*-table designs violate the full-length sliding-GC constraint under both composition rules.

To test generality beyond codon space, we ported GenNav, unchanged in mechanism, to the RNA aptamer design workflow, where after profiling no structure predictor may rank candidates and the generator is a diffusion model whose per-setting quality is mostly sample-level noise (GC intraclass correlation 0.30, each probe sample adding only about 15 percentage points of setting-quality signal). A four-segment pre-registered campaign arc on the 20-target aptamer suite maps where that difference matters (Fig. 5e; both conditions budget-matched at 48 raw candidates per target, zero LLM calls, zero budget violations). Under a delivery-easy constraint matrix both conditions saturate, at 56 of 60 cells each with one discordant cell apiece (P = 1), while the navigator stops early, spending a mean 32.7 of 48 raw candidates for identical delivery (32% fewer). Re-anchored to the production scarce matrix, discordance stays balanced (10:9, P = 1, n = 60). The decisive panel of the 12 most delivery-scarce targets moves to 10:3 in the navigator's favour (24 versus 17 of 36 cells delivered, and end-to-end three-class delivery on 4 targets versus 0, the only completed targets on the panel; Fig. 5f,g) but not past the pre-registered significance gate (P = 0.092, a registered no-go, disclosed), while the delivery-abundant complement inverts the sign (1:8 favouring the static grid, P = 0.039).

Completing the static grid on the six deployment targets, which share the protein structures and hotspots of their form-entry navigation campaigns, pools the paired evidence to 26 targets × 3 profiles (Fig. 5g). Navigation delivers 48 cells to the static grid's 42, with pooled discordance 18:12 (P = 0.36). The deployment cohort alone contributes 7:1 (8 versus 2 cells delivered, P = 0.070) and sits deep in the scarce regime. Navigation ran to the 48-call cap on five of six targets (swine H3 HA the zero-delivery boundary under both conditions), and the deliveries it does make arrive in the closing rounds of its per-round records, IFN-γ stepping up at 29, 35 and 47 raw calls and PDGF-BB only at 36 and 48. Adaptive allocation therefore has a measurable two-sided operating signature, and the campaigns themselves supply the deployment rule (Fig. 5e). Where the quota is scarce relative to the target's difficulty, navigation is decisively better; the pre-registered 39-target budget sweep's starvation cap delivers 10 cells to the static grid's 2 (b:c = 10:2, P = 0.039, the aptamer side's one statistically significant cell-level win, exactly where the starvation mechanism predicts; Supplementary Fig. S2), with navigation leading directionally at 20 (9:4) and at parity at 24 (18 versus 15). Where delivery saturates, navigation reaches the same delivery for about a third fewer generator calls, and where the quota is loose the static grid's exhaustive per-setting depth delivers more cells (32 raw, 10:22, P = 0.050; 48 raw, 12:30, P = 0.008, the regime in which generating everything is cheaper than deciding what to generate). The contrast with the mRNA side is mechanistic rather than accidental. LinearDesign's λ settings are deterministic, so a single probe reads them exactly and navigation wins outright (20:6, P = 0.009), whereas a diffusion generator's setting-quality mapping carries a per-sample noise floor that consumes any exploration budget at this scale.

### The platform outperforms bare-model and tool-using agent baselines across the eleven workflows

A complete platform has to be judged against what a language model alone, or a generic agent scaffold given the same tools, would deliver on the same tasks. We compared three conditions on the 31-session process-aware suite (96 user turns spanning all eleven workflows, identical turn-by-turn inputs). The platform ran as shipped, with its records reused frozen and no re-runs. A bare-model condition used the same underlying model at temperature 0, prompted zero-shot and few-shot, with no tool access. A generic ReAct-style tool-using loop was given the same 41 tools through the same audited executor, plus one environment file-writing primitive, since every tool consumes file inputs that the platform's workflows materialize internally, under model-call budgets matched to the platform's own measured per-session usage and at disclosed 3× and 10× tiers. Every turn was adjudicated by deterministic recomputation under one rulebook for every condition, the platform included. Its frozen outputs were re-adjudicated through the identical checks rather than taken on trust; they pass on every turn, with the four threshold-negative internal ribosome entry site (IRES) answers counted as delivered under the same symmetric negative-answer rule that credits a baseline's complete negative answer. A delivered turn requires structural validity per workflow (length and alphabet, translation identity, target complementarity, window ancestry, structure recovery) and, on the two structure tasks where quality is graded rather than binary, parity with the platform's own best frozen candidate on that same turn. A baseline's fold-back base-pair distance to the target secondary structure, or its alignment template-modelling (TM) score to the target tertiary structure, must match or beat what the platform's frozen best achieved on that turn, a bar fixed turn by turn in advance from the frozen records with no threshold invented for the occasion. Natural-language claims were scored separately, by the blind adjudication rules, with claims whose only possible basis is an unprofiled predictor scored unverifiable for every condition alike.

The platform delivered 96 of 96 turns, the bare model 71 of 96 zero-shot and 69 few-shot, and the tool-using loop 7 of 96 at the platform-matched budget, 44 at 3× and 71 at 10×. Because the platform delivered every turn, the paired discordance reduces to each baseline's own failures. The platform alone succeeded on 25, 27, 89, 52 and 25 turns (zero-shot, few-shot, matched, 3×, 10×), no turn was delivered by a baseline and missed by the platform, and every comparison is significant (exact McNemar, P < 10⁻⁶, n = 96). The failure modes are informative rather than uniform (Fig. 6a,b). The bare model's failures are capability failures, with answers below the platform's structural quality on 14 turns and outright invalid on 11 (zero-shot; 13 and 14 few-shot), whereas the loop's failures at the matched and 3× budgets are almost entirely budget exhaustion without an answer (86 and 42 turns). Every step of the loop is itself a model call, and the matched tier's two calls per turn on the review-bearing sessions, the platform's own review cadence, buy a single tool round trip, one call to request a tool and one to act on its result, leaving nothing for a second attempt. At the generous tier the loop's remaining failures are mostly quality failures (16 turns below parity and nine still exhausting budget). The two baselines tie in aggregate by winning different workflows (discordance exactly 12:12, P = 1.0). The loop wins exactly where computation is indispensable, on tertiary-structure design (4 of 6 turns versus the bare model's 0), sgRNA design (3 of 13 versus 0) and coding-sequence and full-length design, while the bare model wins the small-composition tasks the loop over-spends on, antisense windows (9 of 9 versus 3 of 9, the loop exhausting its step budget on accessibility scans of a long transcript without submitting) and secondary-structure targets of 15–23 nucleotides that direct reasoning solves exactly while the loop's submissions land one to six base pairs off the platform's exact recovery.

Claim behaviour separated the conditions more sharply than delivery (Fig. 6c). The platform publishes no claims from single-workflow sessions by construction, because its claim gate operates on pipeline synthesis reports, whereas both baselines assert freely. The bare model's recomputable claims were false positive at 48.3% zero-shot (95% CI 43.5–53.1) but only 11.4% few-shot, the worked examples anchoring the arithmetic it can do in its head. The tool-using loop's claims carried a 51.9% false-positive rate pooled across its budget tiers (51.1% at the generous tier, CI 44.7–57.5), with 30–37% of its claims unverifiable outright. The ungated-control rate of 54.5% measured earlier in this paper therefore generalizes from our own ungated pipeline to a generic scaffold.

The cost ledger completes the picture (Fig. 6d). The platform completed the entire suite on 146 model calls, all of them quality review, while the loop needed 756 model and 659 tool calls at the generous tier, 5.2 times the platform's model budget, to reach the bare model's delivery rate. On the deterministic workflows (sequence scoring, small-molecule prediction and antisense screening) the platform uses no model calls at all, so the platform-matched budget for those eight sessions is exactly zero, and a loop whose every step is a model call cannot emit so much as its first action. All 24 turns there end in recorded budget exhaustion with no answer, and we report this degenerate floor as measured rather than rescue it. The disclosed generous tiers, whose base is floored at two calls per turn, are where the loop first operates on these workflows, and at 3× it delivers 9 of 9 small-molecule turns, 4 of 6 sequence-scoring and 1 of 9 antisense. Tool access alone therefore buys validity only where computation is indispensable, taxes it everywhere else, and reintroduces ungated claim behaviour. The platform's advantage, full validity at a fifth of the model cost with no false claims, comes from its deterministic workflows and governance rather than from model cleverness.

## Discussion

We showed that three failure modes of agentic science, uncalibrated tool trust, claim overreach and confounded improvement, are not theoretical risks but measurable defaults of a deployed system, and we built RNADesignAgent as a tool-first countermeasure with each mechanism aimed at a specific mode. Capability-layer evidence gating (CapGate) answers the first two. Anchor-set profiling withdraws or certifies each predictor's power before use, the DecisionGate blocks actions whose evidentiary basis is absent, and the ClaimGate downgrades or suppresses claims that exceed the evidence. Generation-layer constraint navigation (GenNav), shipped as a deterministic mode and evaluated exclusively under budget-matched pre-registered protocols, answers the third, together with the platform-wide budget-matching rule that every comparative claim in this paper obeys. The measurements support each mapping. Profiling proved two-sided. It revoked every presumed predictor power we tested on the aptamer chain, with no reliable screening cell (2/27 nominal passes, all confidence intervals covering chance), no reliable ranking cell (4/27, all vacuous) and docking failing in 0 of 19 complexes, while certifying the expression predictor on measured ribosome-load anchors and reproducing a small-molecule predictor's published performance once a silent deployment fault was repaired. Budget-matched self-audit retired our own two strongest legacy claims (survival 0 of 2), establishing confounded improvement as a default state of agentic evaluation rather than a rare accident. The remedies work, at measured cost. Capability gating eliminated false-positive claims on both flagship task families, 0 of 20 claims (95% CI 0–16.1%) versus 54.5% ungated on the aptamer set and 7.7% (1/13) versus 33.3% (6/18) on the mRNA set, a 76.9% relative reduction, while preserving true ones (12/12 on the mRNA set, and 80% on the aptamer set, below our pre-registered 90% gate and reported as measured). Constraint navigation, run deterministically at equal budget, won the registered mRNA paired discordance test against the static condition pooled over 25 targets (20:6, McNemar P = 0.009, n = 75, zero LLM calls, zero budget violations). On the aptamer side the same mechanism mapped a two-sided operating regime rather than a blanket win, decisive at starvation-scale budgets (10:2, P = 0.039 on the 39-target expanded pool) and the only condition completing end-to-end delivery on the hardest panel (4 targets versus 0), with pooled delivery ahead over 26 targets (48 versus 42 cells) but pooled discordance at parity (18:12, P = 0.36) and the decisive panel's significance gate missed and disclosed (10:3, P = 0.092), a boundary measurement that doubles as the deployment rule for adaptive allocation.

The locus of intelligence in a trustworthy agent is not the language model but the *evidence infrastructure* around it, the anchor sets, capability grades, gates and audit trail. This is a principled response to how agentic systems actually fail. Language is where overreach enters, so claims, not just actions, must be gated. Sampling is where confounds enter, so budgets, not just outcomes, must be controlled. Deployment is where tools silently diverge from their papers, so the deployed artifact, not the publication, must be profiled. The multi-agent layer follows the same discipline, with every retained agent's contribution measured rather than assumed. In a per-agent ablation over the full 31-session regression suite, with advisory review off, the retry mechanism off and the production default, every session completed in all three conditions with every per-turn outcome identical across conditions. The quality review is advisory by construction and was verified outcome-neutral at a fixed cost of exactly two calls per reviewed turn, and the retry mechanism fired on two turns and rescued both, the same turns succeeding without it in the ablated conditions. On pre-registered two-node pipelines the deterministic scheduler proved behaviourally transparent, with sequential execution without any agent producing identical node outcomes, while the synthesis agent's report was the only claim-bearing artefact. Of the twelve claims it drafted across the two probes, the ClaimGate rejected five for lacking an evidentiary basis, and with the synthesis LLM disabled no claims were drafted at all. Where measurement falsified a benefit outright, as with the coordination loop, the mechanism was removed rather than retained on plausibility. The same standard holds under external comparison (Fig. 6). On the identical 96-turn suite, the same underlying model used bare delivers 71 turns (69 few-shot), and a generic tool-using loop given the platform's own 41 tools delivers 7 at the platform-matched model-call budget and 71 at the disclosed generous tier, each condition paired against the platform's 96 of 96 with no reverse discordance (exact McNemar, P < 10⁻⁶), while the loop's ungated claims match the ungated-control rate (51.9% false positive against 54.5%) at 5.2 times the platform's model spend (756 versus 146 calls). The platform's advantage is therefore a property of its deterministic workflows and governance, not of the model itself. We also note what calibrated agency is not. It is not autonomous discovery. The system is a scientist-in-the-loop design instrument whose deliverables are candidates, profiles and audit trails, and we emphasize the distinction between calibrated tool orchestration and genuine scientific reasoning. Nor is it a claim that the underlying predictors are weak, only that their power is regime-specific and that the regime must be established before optimization rather than after. Finally, because RNA design touches therapeutic development, dual-use considerations apply. The platform's deterministic gates, off-target scanning and per-call audit trails are guardrails in themselves, and we release the capability map so that others can inherit the boundaries rather than rediscover them.

RNADesignAgent currently has two principal limitations. The two mechanisms are exercised end-to-end on only two RNA types, full-length mRNA design and RNA aptamer design, constrained by how much design procedures differ across RNA types and by the availability of design tools and anchor datasets; GenNav is implemented in these two workflows, and the profiled predictors that back selection and ranking belong to these families. The platform's other workflows run under the same gates and audit trail, with their predictors held to profiled boundaries or require-profiling defaults rather than certified use, and as design tools and anchor data for the remaining RNA types mature, both mechanisms can be extended to the corresponding design workflows. Separately, the anchor sets used to audit and calibrate the predictors for selection and ranking in these two workflows, although assertion-checked and coverage-verified, remain limited in scale. Richer anchor sets will further improve the calibration of the prediction models and, with it, the reliability of the performance they support. Both limitations mark areas for ongoing development rather than fundamental barriers.

More broadly, the artifacts released here, the capability map of widely used RNA predictors, the assertion-curated anchor sets, the budget-matched pre-registration templates and the register of concluded directions, are reusable independently of our system. Any agentic pipeline, in any domain, can adopt the same discipline of profiling before optimizing, gating before claiming and matching budgets before comparing. We anticipate that calibrated agency will become more, not less, important as agents grow more capable, because each added capability enlarges the space of plausible-sounding but unverified actions.

## Methods

### System architecture

RNADesignAgent is implemented as seven layers. L0 (tools) holds 41 scientific tools, each defined by a typed specification (identity, version, endpoint, capabilities, limitations) and exposed through one of 21 local FastAPI microservices, one per external code family, each with its own environment and local model weights. L1 (capabilities) provides thin wrappers that validate tool outputs against their specifications and write audit records (unique per-parameter result keys, per-call timings) into the shared state. L2 (workflows) holds the eleven domain workflows (mRNA CDS design, full-length mRNA design, mRNA sequence scoring, siRNA design, sgRNA design, ASO target screening, IRES prediction, RNA aptamer design, RNA secondary-structure design, RNA tertiary-structure design, RNA–small-molecule interaction), all subclasses of a base workflow that enforces a generate → evaluate → score → rank skeleton with progress events and partial-rerun support; the eleven workflows and the 41 tools are catalogued in Supplementary Tables S2 and S3. L3 (service orchestration) is a service manager that maps each workflow's declared capability requirements to microservices, with file-locked, health-check-gated auto-start. L4 (multi-agent execution) provides a deterministic PipelineAgent scheduling pipeline nodes, a SpecialistAgent per workflow owning retry decisions (hard failures only), the six multi-objective workflows ranking through the shared achievement scalarizing function (ASF) reference-point layer described below, an advisory QualityAgent issuing per-workflow quality reports, and a SynthesisAgent for multi-node reports. L5 (session and workspace) provides per-session workspaces with context-propagated session identifiers and cross-turn result history. L6 (entry) provides a form-driven command-line interface (CLI) and a FastAPI interface through a unified runner, with workflow selection explicit and user-supplied parameters sanitized against workflow input models.

### Multi-agent execution and governance

The multi-agent layer comprises four agents with deliberately narrow roles, and every retained agent's contribution is measured rather than assumed (Results). A PipelineAgent schedules the nodes of multi-node pipelines deterministically, handling input binding, critical failures and final synthesis, and makes no LLM calls. A SpecialistAgent owns each workflow, running it, obtaining a quality review and deciding whether to retry. Retries are confined to hard failures, a run that returned no candidates or whose tool calls errored, because these are objective, reproducible signals whereas a reviewer's dissatisfaction is not. Allowing an LLM's opinion to trigger regeneration would reintroduce exactly the unmeasured adaptivity that the platform's governance is built to exclude. A QualityAgent reviews each workflow's outputs against per-workflow quality benchmarks and issues an advisory report. It can neither trigger a retry nor flip a successful run to failed, and the advisory design is deliberate. If the review call to the LLM fails, the report is marked review-unavailable and recorded as a zero-confidence pass with the error retained for audit, and an abort recommended by the LLM is recorded as advice only. In both paths the run's success is decided by the deterministic workflow, never by the LLM. Three deterministic workflows (mRNA sequence scoring, ASO target screening and RNA–small-molecule interaction) are explicitly exempt from review. A SynthesisAgent drafts multi-node reports, and every claim passes through the ClaimGate before release, so the only LLM-authored text that reaches the user is claim-gated. A bounded coordination loop formerly layered on top of the specialists was removed after a budget-matched control showed its gain was confounded (Results). The sole external LLM used by the platform is DeepSeek (deepseek-v4-pro at the official endpoint, temperature 0.2 for quality reviews and 0.0 when the LLM is itself under test), and all structure and sequence predictors run as local microservices with local weights. Mechanized ranking removes the LLM from the navigation loop entirely, and the navigation campaigns reported in this paper run deterministically with zero LLM calls.

### Candidate ranking by achievement scalarizing reference-point optimization

Every workflow whose candidate pool carries two or more heterogeneous objectives ranks through one shared implementation. Objectives are min–max normalized to [0, 1] within the candidate pool, and candidates are ordered by an augmented Chebyshev ASF against a reference point *r*, defined as ASF(s) = max_i {w_i (r_i − s_i)} + ρ Σ_i |w_i (r_i − s_i)| with ρ = 10⁻³, which guarantees Pareto-optimality of the minimizer. Weights are uniform by default or renormalized from a workflow's existing weight parameters, falling back to uniform whenever a ranking dimension lacks a weight. The reference point is user-supplied in raw units or, by default, the utopian point (pool-best per dimension), and a non-dominated Pareto frontier on raw objective values is always returned alongside the ordering, capped at ten members with per-dimension champions retained. The layer encodes three explicit missing-data policies. A dimension unmeasured across the whole pool, for example a predictor blocked by CapGate or an optional evaluator disabled, drops out of the ranking for every candidate equally, following the CapGate degrade semantics in which components zero or vanish for all candidates and never for some. A dimension missing for an individual candidate, for example a failed or skipped predictor call, is imputed at the measured pool-worst normalized value; omission from the Chebyshev maximum can only lower a candidate's ASF, so a ranking audit replaced the earlier omission semantics, which rewarded evaluation failures, with pool-worst imputation, which additionally leaves the normalization of the measured candidates undistorted. A user reference point covering only part of the measurable dimensions restricts the ranking to that subset and is flagged in the run summary rather than applied silently. This layer serves six of the eleven workflows, full-length mRNA design (CDS quality, 5′UTR ribosome load, full-length folding energy, with the 3′UTR-stability predictor demoted to a report-only diagnostic under the governed two-step protocol of the Supplementary Methods), RNA aptamer design (complex probability, predicted fold confidence, interface score), siRNA design (duplex efficiency, specificity and a nearest-neighbour thermodynamic end asymmetry that favours antisense-strand guide loading, with the full pool ranked before truncating to the requested count), sgRNA design (CRGPT perplexity, CRISOT specificity), ASO target screening (site accessibility, duplex binding free energy) and RNA tertiary-structure design (predicted fold confidence plus two reference-based closeness measures, root-mean-square deviation (RMSD) and TM-score). The remaining five are single-objective, single-candidate or domain-formula tasks where scalarization is vacuous, and they rank directly. ASF values are pool-relative by construction, since ranks are non-monotonic under pool composition and the utopian reference can be attained (ASF = 0), so cross-pool comparisons never compare raw ASF distances and instead use shared fixed reference points, per-objective components or Pareto hypervolume.

### Capability-layer evidence gating (CapGate)

CapGate is fed by a capability self-model, a machine-readable register packaged with the platform and built from the frozen verdict files of the capability audits, which maps each (predictor, task type, target family) tuple to one of four capability grades (screening, ranking, docking or none) with evidence pointers and confidence. The CapabilityProfiler computes grades from anchor-set evaluations against pre-registered thresholds (screening AUROC above 0.8, ranking Spearman ρ at least 0.6, docking native top-1 in at least two of three cases), with a deterministic driver backend. The DecisionGate intercepts planned actions and forbids those whose evidentiary basis is absent. The ClaimGate intercepts outgoing claims and downgrades them along a scope ladder (absolute → same-target relative → trend-only → suppressed), enforcing "no claim without verification". Both gates are deterministic, and every decision is appended to an append-only audit trail. CapGate is a production default of the platform rather than a campaign harness. A process-wide runtime configured by the entry runner (environment switch `RNADA_CAPGATE`, set to off, advisory or enforce, default enforce) records every tool call made by any workflow to the platform audit trail, carrying the name, arguments summary, success, timing, error and gate flag together with the session and workflow identity of the run that made the call, so every line of the append-only trail is attributable to its run. The same runtime reviews the managed predictor tools, the aptamer structure predictors, both GEMORNA UTR predictors and the small-molecule scorer, against the self-model at the single tool-execution choke point, blocking calls whose grade is failed or unprofiled under enforce policy (workflows' existing fallbacks zero the affected component for all candidates equally, so runs complete and the predictor is neutralized rather than crashing), and passes the claims of multi-node synthesis reports through the ClaimGate, with claim extraction as the only LLM step. The profiling evidence travels with the system as a packaged default self-model built from the frozen verdict files of the capability audits, so production gating enforces the published profiling results out of the box. Family transfer in the self-model is conservative, with a never-profiled (predictor, task) family inheriting the donors' worst grade per capability. Anchor sets are assertion-curated. Entries carry role labels (binder, negative, unrankable), internal consistency assertions and negative assertions are checked at build time, and coverage (at least 4 binders and at least 3 negatives per target) is verified before use. mRNA-side anchors follow the same pattern with measured MRL labels substituted for affinities, dichotomized at pre-registered pool extremes (top versus bottom 60 of the read-depth-filtered pool) for the screening grade, with a 120-anchor rank-stratified subset per family for the ranking grade.

### Generation-layer constraint navigation (GenNav)

GenNav comprises four components. A feasibility-first adaptive probe over the generator's discrete settings determines which settings are feasible for a target before the quota of generation calls is allocated, with an explicit infeasibility path when no setting is feasible. Profile-separable delivery imposes per-profile constraint bands for mRNA (expression, stability and balanced) and per-profile length bands for aptamers. A diversity mechanism enforces a minimum pairwise edit distance among the candidates delivered for the same design profile, through a synonymous-diversity expander for mRNA (local codon substitutions that spend no generation budget) and greedy within-batch diversity floors for aptamers. Explicit generator-context resolution supplies species-matched codon tables for mRNA and length and seed settings for aptamers. Constraint matrices are pre-registered per campaign (mRNA matrix, GC content windows, homopolymer runs < 14 bp, initiation-region stems ≤ 12 bp, full-length stems ≤ 30 bp, boundary GC, CAI ≥ 0.8; aptamer matrix, per-profile length bands compact 25–34, standard 40–55 and extended 61–80 nucleotides, per-band GC windows and stem caps, homopolymer runs < 6 nucleotides, and a within-batch normalized edit distance ≥ 0.15 among the five delivered candidates per profile). The generation budget is identical across conditions in every campaign (the budget-matching rule). On mRNA it is 35 raw generator calls per target per condition, the static recipe (the static executor's fixed generator settings, 4 LinearDesign λ values, 1 RNARL run and 30 GEMORNA samples) versus the navigator's budget-matched LinearDesign cap, with pooled mean spend 23.1 and early stop. On aptamers it is 48 raw candidates per target per condition, the navigation condition spending at most four targeted reinforcement rounds of six candidates inside the same cap, with a deterministic guarantee rule that allocates one round to every repairable delivery band before any band receives a second. Reinforcement settings are selected from Laplace-smoothed pass rates fused with the live pool at no extra budget. The decisive aptamer protocol is a production path. The aptamer workflow's opt-in navigation mode runs the densified length-grid probe, the cycling guaranteed-repair allocation and the per-profile delivery deterministically (zero LLM calls), folds every candidate through the audited LinearFold service for the constraint matrix, caps the generation budget at 48 raw candidates, stops early once every profile is deliverable, and writes the complete navigation trace (probe, rounds, per-profile deliveries, degrades) to the run record. The mRNA-side mode follows the same pattern, its parameters calibrated against a re-run of the pre-registered endpoint. It runs a concurrent λ-curve probe over a densified 35-value λ grid, budget-matched reinforcement, and per-profile matrix delivery whose every band dimension carries its registered counterpart value (CAI floor 0.80, CDS-level stems ≤ 30 bp, GC window at the registered sliding bounds, homopolymer < 14), with the synonymous-diversity expander and the complete navigation trace (probe, rounds, expansions, deliveries) in the run record, so a navigation campaign is reproducible from its audit trail exactly like every other platform action. The campaigns that measure this mechanism, the selection-layer pool measurement, the budget-matched endpoint campaigns with their pooled deployment cohorts and the expanded-pool budget sweep, ran under the pre-registered protocols of the Supplementary Methods.

### Benchmarks and anchor sets

Four registered benchmark suites were used. The 210-task platform suite RNADesign-210 spans the eleven workflows. The 20-target full-length mRNA suite covers therapeutic proteins, with two legacy oversized targets, the ZIKV polyprotein and factor VIII, both beyond the LinearDesign memory guard, replaced by OTC and PDGFB with translation-verified RefSeq CDSs. The 20-target aptamer suite covers the aptamer side. The 31-session process-aware multi-turn regression suite exercises all eleven workflows through the user form entry and also serves as the task set of the external-baseline comparison (Fig. 6), whose three conditions run under the protocol registered in the Supplementary Methods. Three further registered assets extend the two flagship suites. A 19-target expanded aptamer pool, 12 RNA–protein complexes from the docking anchor set with protein chains retained plus 7 anchor-set proteins whose structures are predicted on first use, combines with the 20-target suite into the 39-target pool of the aptamer budget sweep. A five-protein mRNA deployment cohort (PTH, leptin, G-CSF, thrombopoietin and PLAT, single UniProt isoforms with accessions and lengths asserted at registration) and a six-protein aptamer deployment cohort (six anchor-set proteins) entered through the production user-form entry, their comparison conditions were completed under the identical budget-matched protocols, and the pooled 25- and 26-target analyses are reported with cohort splits disclosed. Two derived audit task sets support the claim-gating studies (Supplementary Methods). A 45-task aptamer set is built on the nine-target anchor set, from an earlier registered 20-task set carried byte-verbatim and extended by pre-registered construction rules to 24 trusted-deterministic tasks with exactly recomputable ground truth and 21 untrusted-predictor ranking and screening tasks spanning all nine targets. A 20-task full-length mRNA set is built from the same suite's real design assets, with ten trusted-deterministic and ten untrusted-predictor tasks.

External anchor sets ground the capability profiling and the biological-validity controls, and every entry carries a role label and a per-entry source citation. Codon-usage controls are 20 wild-type CDSs fetched from NCBI RefSeq (per-target accessions recorded, translations verified against the benchmark proteins) together with 200 random synonymous controls (ten seeded uniform synonymous resamples per wild-type sequence). Vaccine-mRNA anchors are the assembled BNT162b2 and mRNA-1273 contigs of the published putative-sequence assemblies (Jeong and McCoy et al. 2021). Known aptamers are the thrombin-binding aptamer, pegaptanib and a SARS-CoV-2 nucleocapsid binder, each with its literature Kd. The aptamer binder and negative panels (95 entries over nine protein targets, 62 binders with measured Kd) and the 19 solved RNA–protein complexes (14 independent protein targets) are curated from literature affinities and RCSB Protein Data Bank structures. The IRES literature panel holds nine experimentally validated IRES 5′UTRs, six viral (EMCV, HCV, poliovirus, FMDV, rhinovirus A1 and BVDV-1, with RefSeq 5′UTR ranges) and three cellular (c-myc, VEGF-A and BiP, with validating publications including Stoneley et al. 1998, Stein et al. 1998 and Yang and Sarnow 1997), against 50 random human 5′UTRs as negatives. Small-molecule binder and non-binder pairs comprise the theophylline aptamer (PDB 1O15, theophylline versus caffeine, roughly 10⁴-fold discrimination; Jenison et al. 1994), HIV-1 TAR (1ANR, aminoglycoside binders versus non-binder controls) and the guanine riboswitch (1Y27, guanine versus adenine and caffeine), with RNA sequences taken from the PDB records, and the small-molecule predictor's held-out ROBIN and PDB test splits and its decoy case studies follow the predictor's published evaluation. An mRNA-stability panel of 400 constructs with measured reactivities and degradation rates derives from the stability predictor's upstream public test set. The measured-MRL 5′UTR anchor families derive from the published massively parallel translation assay (Sample et al., Gene Expression Omnibus (GEO) accession GSE114002).

### Statistics

Paired comparisons used two-sided Wilcoxon signed-rank tests with Cliff's δ as effect size, and multiple-testing control used Benjamini–Hochberg false discovery rate (FDR). AUROC confidence intervals used 10,000-fold bootstrap. The GenNav primary endpoints used exact paired McNemar tests on per-profile joint-criteria pass/fail. The baseline comparison (Fig. 6) uses the same exact paired McNemar tests on per-turn delivered validity (n = 96 turns) with Wilson 95% confidence intervals on claim false-positive rates, and its per-workflow delivery counts, failure-mode decomposition and cost ledger are reported verbatim from the frozen comparison records. On mRNA, the pooled analysis covers n = 75 pairs = 25 targets × 3 profiles, the 20-target pre-registered cohort plus the five-target deployment cohort, whose navigation cells are the frozen form-session records and whose static conditions were completed under the identical budget-matched protocol (cohort split disclosed, with the pre-registered 20-target cohort verdicts remaining the inferential backbone). On aptamers, each arc segment uses n = 60 pairs over the 20-target suite, the decisive panel n = 36 pairs = 12 targets × 3 profiles and its confirmation n = 24, the expanded budget sweep a 39-target pool per cap, and the pooled summary n = 78 cells = 26 targets × 3 profiles, reported with cohort splits disclosed. Predictor ranking grades used Spearman correlation against measured values (Kd or MRL). Thresholds were pre-registered per campaign (for example δ ≥ 0.3 for pilot go gates, AUROC above 0.8, ρ at least 0.6, and FDR q < 0.05 with |δ| at least 0.3 for design gains). Experiment orchestration was assisted by a coding agent external to the tested system.
