# Calibrated agency: a tool-first RNA design agent that profiles its oracles and gates its own claims

## Abstract

RNA design depends on specialized computational tools whose orchestration remains expert manual work. Large-language-model agents could automate this, but we show they exhibit three measurable failure modes: uncalibrated tool trust, claim overreach and confounded improvement. On curated anchor sets, three deployed structure oracles lost all presumed screening, ranking and docking power (0/18 cells); an ungated agent issued 57.9% false-positive claims; budget-matched controls dissolved our own apparent coordination gains. We present RNADesignAgent, a tool-first calibrated agent for eleven RNA design workflows: oracles are profiled before use, deterministic gates check actions and claims against that self-model, and comparisons are pre-registered and budget-matched. Gating eliminated false-positive claims while preserving true ones on both flagship task families — aptamer-chain and synthetic tasks (57.9% → 0%) and full-length mRNA design-reporting tasks (38.9% → 8.3%); generation-layer constraint navigation delivered pre-registered multi-constraint profiles where a rule-based executor failed — decisively on mRNA (McNemar P = 1.9 × 10⁻⁹) — and, on aptamers at equal budget, won the discordant cells 14:3 after lattice densification and starvation-free allocation (McNemar P = 0.013). Calibrated agency makes agentic science auditable.

## Introduction

RNA has become a therapeutic modality of central importance, from mRNA vaccines to small interfering RNAs, guide RNAs, antisense oligonucleotides and aptamers. Designing these molecules is a multi-objective problem: an mRNA coding sequence must balance codon optimality, secondary-structure stability, translation initiation context and UTR-mediated regulation; an aptamer must fold, bind and remain specific; every candidate must additionally satisfy manufacturability and safety constraints. The field has responded with a constellation of specialized computational tools — sequence optimizers, structure predictors, expression and stability models, off-target scanners — each excellent within its remit and silent outside it. No single tool spans the pipeline, and chaining them into a coherent design campaign remains expert manual work that can take days per target.

LLM-driven agents are a natural candidate to automate this orchestration, and recent systems have demonstrated agentic hypothesis generation, data analysis and tool use across the sciences. We reasoned that such agents, when deployed over real predictive tooling, should exhibit three recurrent failure modes — and that measuring them is a prerequisite for fixing them. First, **uncalibrated tool trust**: agents consume the outputs of predictive models — binding scores, folding energies, expression predictors — at face value, without validating whether a given model has any demonstrated power for the task, target family or molecular regime at hand. Second, **claim overreach**: because agents narrate their own results in natural language, statements can drift beyond what the underlying measurements support, and such statements are difficult to audit after the fact. Third, **confounded improvement**: agent systems are frequently evaluated by comparing best-of-pool outcomes across conditions, but agentic strategies typically also *generate more candidates*, so that an apparent optimization or coordination gain may be nothing more than a larger sampling budget.

In this work we first demonstrate that all three failure modes are real and measurable in a deployed agentic system — ours — and then present **RNADesignAgent**, a tool-first calibrated agent for RNA design built to counter them. In a calibrated agent, every predictive oracle is profiled on curated anchor sets before use, yielding an empirical self-model of what each tool can and cannot establish; every action and every natural-language claim passes through deterministic gates that check it against this self-model; and every comparative evaluation follows a pre-registered, budget-matched protocol so that gains are attributable to mechanisms rather than to sampling. Our key contributions are:

1. **A tool-first RNA design platform.** Eleven domain workflows composed from 54 tools exposed as 22 local microservices, with deterministic pipelines, interface-locked contracts, service pre-flight, and full per-tool-call audit trails. The LLM orchestrates and reviews but never generates sequences directly. We validate that the platform produces biologically meaningful outputs at scale across all eleven workflows.
2. **The calibrated-agency stack, with direct evidence that it is needed and that it works.** An empirical capability-profiling protocol that maps each (oracle, task type, target family) combination to an evidence-backed grade, feeding two deterministic gates — a DecisionGate that forbids actions whose evidentiary basis is absent, and a ClaimGate that degrades or suppresses natural-language claims exceeding the evidence. Profiling and gating are one mechanism: the profile is the gate's evidence base. We show the failure modes it counters are present in an ungated system, and that gating eliminates false claims while preserving true ones in measured gated-versus-ungated comparisons on both flagship task families — the aptamer-chain and synthetic audit set (57.9% → 0%) and a second, mRNA-side audit set built from real full-length design-reporting tasks (38.9% → 8.3%; E3-M), with true positives preserved in both.
3. **Generation-layer constraint navigation (GenNav).** A feasibility-first generator-navigation strategy that delivers batches of candidates satisfying pre-registered multi-constraint profiles — the regime where an agent can demonstrate value beyond a single tool's native reach. We show it succeeds decisively where a rule-based executor fails on full-length mRNA design, and that the same machinery transfers unchanged to RNA aptamer design, where it repairs rule-based delivery failures at equal budget.

## Results

### System overview: a seven-layer tool-first agent

RNADesignAgent is organized as seven layers (Fig. 1). At the base (L0), each of 54 tools — wrapping 20 vendored external research codes (17 as git submodules) — runs in its own environment behind one of 22 local HTTP microservices (ports 8003–8024), so that heavyweight GPU models (RhoFold, Protenix, EGARPS, ODesign), CPU optimizers (LinearDesign, LinearFold, ViennaRNA) and alignment suites (BLAST+, Bowtie2) are invoked through uniform, versioned contracts. Tool specifications (L0), capability wrappers that validate outputs and write per-call audit records (L1), and eleven domain workflows with a fixed generate → evaluate → score → rank skeleton (L2) are all deterministic; a service manager (L3) maps each workflow's declared requirements to microservices, health-checks them, and auto-starts what is missing. The multi-agent execution layer (L4) comprises a PipelineAgent that schedules workflow nodes deterministically, per-workflow SpecialistAgents, an advisory QualityAgent that reviews outputs against per-workflow quality profiles, and a SynthesisAgent for multi-node reports; a deterministic CoordinatorAgent runs a bounded coordination loop for the two coupled workflows, retained as an auditable budget-allocation mechanism whose coordination benefit we tested and falsified (see below). Session memory and workspace management (L5) and the CLI/FastAPI entry façade (L6) complete the stack. Two governance mechanisms cut across all layers: interface locks, which pin every tool and workflow contract to a synchronized documentation and test surface, and the calibrated-agency stack (SelfModel, CapabilityProfiler, DecisionGate, ClaimGate, AuditTrail), which carries the agent's empirical knowledge of its own tools.

Two design commitments distinguish the platform. First, the LLM never writes sequences: every molecule is produced by a validated generator, and the LLM's roles are restricted to orchestration, review and reporting, which makes every design decision traceable to a deterministic tool call. Second, every comparative claim the system or its operators might make is constrained to follow a pre-registered, budget-matched protocol, so that reported effects are attributable to mechanisms rather than to sampling effort.

### The platform produces biologically valid outputs at scale

We first established that the platform's outputs are biologically meaningful across all eleven workflows, using a 210-task benchmark together with designed null models and literature anchors (Fig. 2). All 210 tasks completed successfully. (The single failure in the legacy run — a QualityAgent abort on a GC-rich siRNA target — was an artifact of an earlier governance version in which an LLM advisor could abort a run; under current governance, where advisory aborts cannot fail a run, the task completes in 91 s. We report the rerun.) Three observations anchor biological validity. (1) On 20 wild-type protein targets, designed coding sequences reached a median codon adaptation index (CAI) of 0.745 (n = 20), exceeding wild-type sequences (median 0.729, n = 20), which themselves exceed random synonymous sequences (median 0.672, n = 200; Mann–Whitney P = 4.0 × 10⁻⁷, Cliff's δ = 0.69) — the platform reproduces the direction of natural selection and improves on it, while wild-type and random sequences are indistinguishable on folding energy per nucleotide (P = 0.23), confirming that the CAI signal is not a folding artifact. Two attribution notes are in order: the designed sequences are produced by the LinearDesign generator running a pure CAI objective (λ = 0), so the CAI lift over wild type is a *tool-level* capability — the platform's contribution is to expose it as a one-call, audited, end-to-end deliverable; and the wild-type-over-random ordering confirms that the CAI assay itself reports a biologically meaningful direction. (2) Inverse folding against target secondary structures recovered the exact target structure for 22 of 25 benchmarks — again a tool-level capability that the platform packages into an auditable workflow. (3) On a literature panel of IRES elements, the platform's predictor achieved an AUROC of 0.762 (95% CI 0.429–0.98).

The small-molecule panel deserves a fuller account, because it became the worked example of why profiling must target the *deployed* oracle rather than the literature. In an initial assessment, small-molecule binding scores on short aptamers performed at chance — apparently an out-of-training-distribution boundary. A boundary audit then revealed the full picture (Fig. 2d). On RNAsmol's own held-out test distributions, the deployed service initially failed to reproduce the tool's published performance (AUROC 0.786 and 0.410 on the ROBIN and PDB test splits); tracing the divergence identified a preprocessing mismatch in our service wrapper — the model's case-sensitive RNA encoding (lowercase denoting modified bases) was being collapsed to uppercase, and the molecular-graph adjacency differed from the upstream training pipeline. After restoring upstream-faithful preprocessing, the deployed service reproduces the official reference evaluation exactly (AUROC 0.974 and 0.983 on the two test splits; the true ligand ranks 2nd of 1,601 and 7th of 265 decoys in the two published decoy case studies), while the short-aptamer panel remains outside validated power (binder-versus-random-chemistry AUROC 0.722, 95% CI 0.278–1.0; binder-versus-near-cognate 0.563, 95% CI 0.063–1.0 — both consistent with chance and far below any screening threshold). The boundary is real, but it is now demonstrated from both sides: the oracle has strong, exactly reproducible power inside its training distribution and no demonstrated power outside it — and only profiling the deployed artifact, rather than trusting the publication, caught the silent deployment degradation. End-to-end, the platform completes full design campaigns in minutes to about an hour per target (Supplementary Table 1).

### Three failure modes of agentic science, measured

**Uncalibrated tool trust.** The platform's throughput makes it tempting to treat its most sophisticated scorers as oracles for optimization. To test whether that temptation is survivable, we profiled the three structure-based oracles deployed in the aptamer workflow — EGARPS native probability, Protenix ipTM, and RhoFold pLDDT — on assertion-curated anchor sets spanning six protein targets (66 sequence entries with binders, negatives and affinity series; 102 docking poses across five RNA–protein complexes with known native structures). Each (oracle, target) cell was graded against pre-registered thresholds for three capabilities: screening (binder-versus-negative AUROC > 0.8), ranking (Spearman ρ ≥ 0.6 against measured Kd), and docking (native pose ranked top-1 in ≥ 2/3 of cases) (Fig. 3).

No cell passed. Screening power was absent in 0/18 oracle–target cells; the best cell (RhoFold pLDDT on PDGF-BB) reached AUROC = 0.8 exactly with a 95% confidence interval of 0.33–1.0, still below the strict threshold. No oracle approached ranking power (best ρ = 0.56). Docking failed in 0/5 cases: the native thrombin aptamer (TBA) pose ranked last of 21 candidates, and the best native rank across all cases was 4 of 18. An independent calibration panel gave the same verdict from the affinity side: across a four-point thrombin Kd series, EGARPS native probability correlated at ρ = 0.40, and binders scored *below* negatives on average (AUROC = 0.356) — the marketed drug pegaptanib scored ~2 × 10⁻⁶ while a 30-nt random RNA scored 0.95 and a scrambled TBA 0.99. In other words, the scoring chain as deployed not only lacks screening power but is directionally inverted on this molecular family. These results do not imply the oracles are broken; they imply that their published validation regimes do not transfer to RNA–protein aptamer complexes, and that any agent using them for ranking or screening without profiling would be optimizing against noise — or worse, against anti-correlated signal.

Profiling is equally able to *certify* power where it exists, which is what makes the resulting capability map a usable self-model rather than a list of prohibitions. We profiled the full-length mRNA workflow's expression oracle — the GEMORNA 5′UTR mean-ribosome-load (MRL) predictor — on 706 measured-MRL anchor sequences curated from a published massively parallel translation assay (Sample et al.; GEO GSE114002), using the same pre-registered gates. The oracle passed decisively on all three target families: on the in-training-distribution random 50-nt library, screening AUROC = 0.990 (95% CI 0.975–1.0) and ranking Spearman ρ = 0.926 against measured MRL (n = 120 ranking anchors); on the varying-length (25–100 nt) random and human-endogenous libraries, screening AUROC = 1.000 for both and ρ = 0.920 and 0.835 respectively. The same audit classified the platform's 3′UTR stability predictor as *unprofiled* — no measured-stability anchor set exists — and the DecisionGate accordingly requires profiling before any ranking action may rely on it (Fig. 3d). Together with the RNAsmol two-sided result above, the capability map (Fig. 3) defines, for every deployed oracle the agent leans on, where optimization claims are void, where they may be entertained, and where evidence is simply absent.

**Claim overreach.** Because agents narrate their results, overreach is the failure mode that enters through language. We measured it directly on a synthetic audit set of 20 design-reporting tasks: an ungated agent, given the same prompts and the same underlying LLM, issued false-positive claims at a rate of 57.9% (11/19 claims), with 23 recorded events of statements exceeding the scope the evidence sanctioned — for example, asserting candidate superiority from an oracle with no measured ranking power (Fig. 4c, ungated arm).

**Confounded improvement.** The third failure mode we found in our own earlier results. RNADesignAgent's bounded coordination loop had previously shown an apparent main effect on the aptamer workflow: coordination raised the EGARPS-component score over serial execution (paired Wilcoxon P = 2.1 × 10⁻⁴, Cliff's δ = +0.46, n = 19 targets) and raised the three-objective hypervolume (P = 2.6 × 10⁻⁴). Two confounds, however, were visible in the design: each coordination round doubles the evaluation pool (8 → 16 candidates), and the headline metric is exactly the oracle that profiling had just decertified. We therefore pre-registered two decisive controls (Fig. 4a). In a budget-matched control (P0), coordination was compared against serial execution extended to the same 16-candidate budget; the advantage collapsed below the pre-registered effect-size gate (δ = 0.278 < 0.3, P = 0.13, 12 cells). In a guided-versus-unguided control (P3), the diagnostic content of coordination was replaced by a fixed resampling instruction with identical mechanics and budget; guidance added nothing (δ = 0.222, P = 0.11). Consistent with these pilots, the full-length mRNA coordination campaign showed no significant effect at any coordination depth on the fixed-reference scalarization (coordinated versus serial P = 0.81, n = 20 targets), and no mechanism-ablation test survived false-discovery-rate correction. A formal self-audit of our two strongest legacy claims — the aptamer coordination effect and a case-study comparison against pegaptanib — using the four-step protocol (declare capability dependencies, re-check against profiles, control confounds, gated re-adjudication) retired both: claim survival 0/2, below the pre-registered 70% threshold (Fig. 4b). The coordination loop is retained in the platform — its bounds, clamps and traces make it an auditable budget-allocation mechanism — but we claim no coordination benefit for it, and we treat budget matching as an iron rule for every comparative claim in this paper.

### The calibrated-agency stack: gates that know their evidence base

The remedy for the first two failure modes is a two-layer deterministic gate fed by the capability self-model (Fig. 4c). The DecisionGate intercepts planned actions and forbids those whose evidentiary basis is absent from the self-model (for example, ranking candidates by an oracle with no measured ranking power); the ClaimGate intercepts outgoing natural-language claims and downgrades them along a scope ladder (absolute → same-target relative → trend-only → suppressed), enforcing "no claim without verification". Both gates are deterministic, and every decision is appended to an audit trail, so the agent's epistemic behavior is itself auditable.

We evaluated the stack on the 20-task audit set under two arms with identical prompts and the same underlying LLM: an ungated arm and a gated arm, with claims adjudicated blind to arm by a deterministic adjudicator. On the pre-registered endpoints, gating reduced the false-positive claim rate from 57.9% (11/19 claims) to 0% (0/11) — a 100% relative reduction against a ≥ 50% gate — while true-positive retention was 112.5% (9/8; gating also *rescued* one claim the ungated arm had buried). Overreach events numbered 23 in the ungated arm and zero in the gated arm, a hard guarantee of the DecisionGate rather than a statistical outcome. Notably, the mechanism of gating is abstention and downgrading, not silence: the gated arm still issued claims, but only within validated scope. A pilot of this experiment had initially failed (gating did not reduce false positives at small scale because the LLM, when blocked, substituted an undeclared free proxy), illustrating that gating must close *all* unverified claim paths — a protocol lesson now encoded in the pre-registration template. On the mRNA side, the same gates behave selectively rather than universally prohibitive: ranking by the MRL oracle is permitted on the target families where profiling certified it, is transferred only with decayed confidence on never-profiled families of the same oracle, and actions relying on the wholly unprofiled 3′UTR stability predictor are blocked pending evidence. To extend the measurement to the mRNA flagship family, we built a second 20-task audit set (E3-M) from real full-length mRNA design-reporting tasks — ten with exactly recomputable ground truth (CAI, folding energy, constraint satisfaction on E6 campaign CDSs; measured-MRL anchors on the certified family) and ten whose evidence basis the E7 profile denies or degrades (3′UTR stability and junction metrics as decoys; absolute expression claims on never-profiled families). On identical prompts and two LLM calls per task, gating reduced the false-positive claim rate from 38.9% (7/18) to 8.3% (1/12) — a 78.6% relative reduction — with true-positive retention of 100% (11/11) and zero decision-layer overreach events in the gated arm; the one surviving gated false positive traces to a predicted-versus-measured MRL rank flip on the varying-length human family (ρ = 0.835), a ground-truth property both arms face symmetrically.

Two platform-level governance results complement this. On the 19-task process-aware regression suite, runs with and without the advisory quality-review agent both succeed 19/19, confirming that the LLM advisor is not a hidden dependency for success; and a governance fix informed by two production incidents now guarantees that LLM advisory failures (for example, API outages) can never convert a successful run into a failure — review unavailability is recorded as audit metadata, not as a verdict.

### Generation-layer constraint navigation delivers pre-registered design profiles — on both flagship tasks

Where, then, can an agent demonstrate value beyond a single tool's native reach? Our answer, arrived at through a failed experiment, is *multi-constraint batch delivery*. Single-metric quality (CAI, folding energy) is essentially determined by the underlying generator's settings — within the tool's own range, an agent adds nothing. The defensible agent task is to deliver, per target, a ranked batch of candidates that jointly satisfy a pre-registered constraint matrix across multiple design profiles.

A first attempt placed constraint navigation in the selection layer: a fixed candidate pool (315 sequences per target: four LinearDesign λ settings, one RNARL candidate, thirty GEMORNA candidates) was filtered and ranked. This campaign met its end-to-end delivery and constraint-satisfaction gates (constraint rate 1.0; delivery at ceiling), and mechanizing the ranking (system-enforced utility order with the LLM restricted to tie arbitration) cut LLM involvement to three calls with perfect rank correlation (Kendall τ = 1.0). But the campaign failed its diversity gates overall: on insulin the batch pairwise edit distance fell to 0.82% (< 2% required) because admissible candidates saturate a single λ setting; on GFP only two λ gears were usable until a species-matched *E. coli* codon table was passed through (pool pass 0/315 → 12/315). Every residual failure was structural to the generation layer — λ-gear separation, λ saturation, feasible-gear coverage — not to the coordination or gating machinery (Fig. 5a).

We therefore sank constraint navigation into the generation layer (GenNav): a feasibility-first adaptive λ probe (λ ∈ {0, 2, 8, 20, 50}) that establishes which gears are feasible per target before allocating budget; profile-orthogonal generation axes (CAI-max, fractional, floor) that make design profiles separable by construction; a diversity expander enforcing ≥ 3% pairwise distance within delivered batches; and explicit codon-context resolution for non-human expression hosts. Evaluated on 18 mRNA targets under pre-registered dual endpoints, GenNav met the primary endpoint decisively: per-profile joint-criteria delivery passed for the gated navigation arm and failed for the rule-based arm in all 30 discordant pairs (McNemar P = 1.9 × 10⁻⁹, 30:0, n = 54 = 18 targets × 3 profiles), with gene-level end-to-end delivery at 1.0 (Fig. 5b). The stricter secondary endpoint — a quality bundle over all arms — did not pass and is disclosed rather than hidden: essentially all quality failures trace to a single target, HER2, for which the feasibility probe found *no* feasible λ gear and the system degraded gracefully by design. Total LLM usage for the 18-target campaign was 43 calls (mean 2.4 per gene), below the pre-registered budget (Fig. 5c).

To test whether the strategy generalizes beyond codon-space navigation, we ported GenNav to the aptamer workflow, where the generator (ODesign) exposes a different gear set — aptamer length, random seeds and sample count — and where, post-profiling, no structure oracle may be used for selection. The aptamer instantiation navigates a length lattice with feasibility-first probing and delivers, per target, three length-banded profiles (compact 25–39 nt, standard 40–60 nt, extended 61–85 nt) under a sequence-level constraint matrix (GC windows, homopolymer and stem caps, within-batch diversity), at a generation budget identical to the rule-based arm (Fig. 5d). On 10 targets (30 pre-registered profile pairs), the gated navigator repaired every rule-based delivery failure it met — the static grid failed the extended band on VEGF and SARS-CoV-2 Nucleocapsid and the compact band on BSA, and the navigator delivered all three by reallocating its capped budget toward the scarce bands with fresh seeds — while itself falling one candidate short on MBP's compact band after mis-prioritizing its four reinforcement rounds (discordance 3:1, McNemar P = 0.625). The primary endpoint is therefore not met on this task: 26 of 30 pairs pass under both arms, and a navigator cannot demonstrate an advantage where the static pool already suffices — the same saturation logic that retired the selection-layer campaign above. What the campaign does establish is mechanical generality at equal or lower cost: the unmodified GenNav machinery (probe, gates, allocation, degrade path) transferred to a structure-guided generator with no task-specific changes, delivered at 0.9 versus 0.7 end-to-end rates while spending fewer candidates (mean 36 versus 48 per target), never violated a budget or gate, and had the DecisionGate refuse oracle-based ranking in all ten runs. GenNav thus both demonstrates the agent's value regime and delineates its current boundary: navigation earns its keep where the generation layer makes delivery hard — codon-objective trade-offs on mRNA, scarce-band allocation on aptamers — and where the underlying generator family has no feasible operating point at all, the honest outcome is a declared degradation rather than a silently weaker delivery. A second campaign (E9) confirmed that the boundary is budget structure rather than mechanism: a re-anchored gear-scarce matrix raised rule-based delivery failures from 3/30 to 11/30, but four reinforcement rounds could not reliably hit scarce anchor lengths from noisy two-sample probe estimates, and the navigator conceded eight cells (b = 6, c = 8, McNemar P = 0.79). Mechanizing the reinforcement decision with a deterministic gap-weighted allocator (E10) raised discordance to 9:4 (P = 0.27); a densified length lattice (17 lengths, ~3 nt per band) with S1-measured laplace priors (E12) halved the static grid's concessions and improved discordance fourfold to 9:2 (P = 0.0654); and a controlled replication with a direct panel rule (E13) reproduced that result cell-for-cell. Closure analyses across these campaigns — protocol simulation (E11), a 324-variant matrix sweep (E12), and the panel replication (E13) — established why the campaigns' absolute end-to-end gate could not be met: at the 48-raw cap, 12 of the 36 profile cells are jointly infeasible, the static arm failing there as well, so an absolute delivery gate of 0.8 measures the target set rather than the navigator. The aptamer primary endpoint was accordingly revised, and the revision was pre-registered before the decisive run: the primary endpoint is the direct relative-advantage test — paired McNemar on per-profile joint-criteria delivery at equal budget — with end-to-end delivery disclosed as a secondary outcome. Under this endpoint, adding a guaranteed-repair allocation (a deterministic cycling rule that spends one reinforcement round on every repairable band before any band receives a second, eliminating the per-band starvation that had repeatedly cost single cells), the decisive campaign (E14, 12 targets, panel chosen by the same pre-registered rule as E13) won the discordant cells 14:3 (McNemar P = 0.0127, n = 36): the navigator delivered 26 of 36 profile cells against the static grid's 15 (72% versus 42%), completed end-to-end delivery on 6 of 12 targets against none (relative full delivery 6:0), spent no more candidates than the rule-based arm (both capped at 48 raw per target), never violated a budget or gate, and required a single LLM call across the entire 12-target run — the guarantee rounds are deterministic. Three A-wins (MBP extended, Papain compact, Thrombin extended) and seven jointly-infeasible cells are disclosed rather than hidden. The aptamer campaign thus completes the same-budget demonstration on the second flagship family: navigation earns its keep where the generation layer makes delivery hard — codon-objective trade-offs on mRNA, scarce-band allocation on aptamers — and the validated levers are lattice densification, measured priors, and starvation-free allocation. The absolute end-to-end gate remains structurally unreachable at this budget for both arms and is reported as a target-set property rather than a navigator failure.

### End-to-end case studies

Three end-to-end cases illustrate calibrated operation (Table 1). (A) A full-length SARS-CoV-2 Spike mRNA campaign (CDS design × UTR presets, full-length evaluation, bounded coordination) completed in 85 minutes; the best candidate's CDS CAI (0.946) approaches the BNT162b2 anchor (0.952), and under the platform's junction metric the designed candidate and the marketed-vaccine anchor are *both* flagged — a concordance that first taught us to treat that metric as a soft reference rather than a pass/fail gate, and ultimately motivated the validated full-length ddG reporter described below. (B) An anti-VEGF aptamer campaign completed in 47 minutes; its top candidate scores 0.70 on the EGARPS component where the pegaptanib anchor scores ~5 × 10⁻⁷ — a six-orders-of-magnitude gap that, post-profiling, we report *not* as a superiority claim but as the worked example of the self-audit: the oracle lacks screening power on this family, the complexes come from incomparable sources, and the anchor's 2′-fluoro modifications are unrepresentable to the scorer. (C) An NSP12 siRNA campaign with off-target scanning completed in 73 seconds, with all top-five candidates showing zero predicted off-targets against the reference transcriptome. Each case ships with a complete audit trail: every tool call, parameter, and intermediate metric is recorded in the session workspace.

### A quantified failure analysis delineates the system boundaries

Across the platform campaigns (~1,400 runs), we classified every failure (Fig. 6a). The overwhelming majority of failure events were transient and fully recovered by resumable sweeps (188 infrastructure failures and 20 timeouts recovered; six driver bugs fixed in place); 35 final failures remained in the legacy record, and all of them are deterministic boundaries or explicit governance outcomes: ODesign produced zero candidates on ferritin-family targets (24 cells), eight runs of a nominal second-LLM arm failed on an endpoint misconfiguration, two oversized targets exceeded the LinearDesign memory boundary (now fail-fast under an address-space guard; the current benchmark panel replaces them with two 200–400-aa targets), and one legacy quality abort — which we show above completes under current advisory-only governance. Three further boundaries deserve emphasis as scientific findings. First, junction repair has no free lunch (Fig. 6b): three independent pre-registered attempts to repair 5′UTR–CDS junction burial — post-hoc codon shuffling with a stability-weight sweep, a junction-penalized global-fold optimizer (a purpose-built LinearDesign patch that drives junction-window pairs from 43 to 0 without repairing the fragment-fold burial metric, a coordinate-system mismatch), and a generate-and-select route against a validated full-length constrained-fold ddG metric (constraint obedience 216/216; LinearFold-versus-Vienna r = 0.945) — all failed their acceptance gates because opening junctions costs global stability. The ddG metric itself passed validation and is now the platform's reporter; the repair direction is abandoned, and we regard this triple of negative results as a durable contribution to the mRNA design community. Second, cross-campaign memory does not pay (Fig. 6c): a 120-campaign dual-endpoint trial of experience injection cut evaluation budgets by 74.2% (814 versus 3,153 evaluations) but produced no learning-curve improvement (all three seed-group slopes positive; P = 0.91) and no design-quality gain (four metrics, all non-significant) — the strategy was abandoned, and the negative result is registered to discourage repetition. Third, the generator boundaries themselves: ODesign's zero-output target class and LinearDesign's memory ceiling are exactly the kind of tool limits a calibrated agent must know before, not after, planning a campaign.

## Discussion

In this work we first showed that three failure modes of agentic science — uncalibrated tool trust, claim overreach and confounded improvement — are not theoretical risks but measurable defaults of a deployed system, and then presented RNADesignAgent, a tool-first calibrated agent built to counter them. Three findings carry the argument. First, capability profiling revoked every presumed oracle power we tested on the aptamer chain (0/18 screening cells, 0/5 docking cases), while certifying power where it genuinely exists — the same protocol confirmed the expression oracle's ranking power on measured-MRL anchors and reproduced a small-molecule oracle's published performance exactly once a deployment preprocessing fault was repaired. Profiling is thus a two-sided instrument: it tells an agent not only what it may not do, but what it may. Second, a budget-matched self-audit retired our own headline claims, showing that confounded improvement is likewise a default state of agentic evaluation; we now treat budget matching as an iron rule. Third, the remedies work: deterministic double gating eliminated false claims while preserving true ones on the aptamer-chain and synthetic audit tasks (57.9% → 0%) and reproduced the effect on a second, mRNA-side audit set built from real full-length design-reporting tasks (38.9% → 8.3%, true-positive retention 100%), and generation-layer constraint navigation delivered pre-registered multi-constraint profiles with decisive significance on mRNA (McNemar P = 1.9 × 10⁻⁹) at a cost of 2.4 LLM calls per gene — and the identical machinery, re-pointed at a structure-guided generator with an entirely different gear geometry, and, on aptamer targets at identical budget, won the discordant cells 14:3 after lattice densification and a guaranteed-repair allocation (McNemar P = 0.013), with a single LLM call across the 12-target run and end-to-end delivery 6:0 in the navigator's favour.

A central insight is that the locus of intelligence in a trustworthy agent is not the language model but the *evidence infrastructure* around it: the anchor sets, the capability grades, the gates, the audit trail. This design choice is not merely a practical compromise but a principled response to how agentic systems actually fail: language is where overreach enters, so claims — not just actions — must be gated; sampling is where confounds enter, so budgets — not just outcomes — must be controlled; and deployment is where tools silently diverge from their papers, so the *deployed* artifact — not the publication — must be profiled. We also note what calibrated agency is not. It is not autonomous discovery: the system is a scientist-in-the-loop design instrument whose deliverables are candidates, profiles and audit trails, and we would like to emphasize the distinction between calibrated tool orchestration and genuine scientific reasoning. Nor is it a claim that the underlying oracles are weak — only that their power is *regime-specific*, and that the regime must be established before, not after, optimization.

Several limitations mark opportunities for continued development. (1) All validation is computational; the anchors and nulls are literature-derived, and no wet-lab confirmation was performed. The profiling protocol, however, is wet-lab-ready: anchor sets accept new measurements as first-class rows, and capability grades update without code changes. (2) A single LLM backend (DeepSeek) was used for the in-system language roles. Multi-backend replication was descoped by decision: the gated roles are narrow (tie arbitration, claim drafting), the gates themselves are deterministic and model-agnostic by construction, and the platform-level result that quality review is advisory-only (19/19 with and without) bounds the backend's influence on outcomes. (3) The rule-based comparator in the navigation experiments is deliberately simple; the discordance should be read as evidence that constraint navigation is necessary, not that every alternative heuristic would fail. (4) The navigation quality bundle fails on targets with no feasible generator operating point (HER2 class); expanding the generator family or the λ lattice for such targets is the next methodological step and is being handled under the same pilot-first discipline. (5) Capability profiles currently cover the aptamer-chain structure oracles, the mRNA expression oracle and the small-molecule scorer; the platform's remaining predictors (for example, the 3′UTR stability model) carry only their literature validation until profiled, and the anchor sets, though assertion-curated and coverage-checked, remain modest in size; community contribution of anchors would directly strengthen the self-model. Overall, these represent areas for ongoing development rather than fundamental limitations.

More broadly, we believe the artifacts released here — the capability map of widely used RNA oracles, the assertion-curated anchor sets, the budget-matched pre-registration templates, and the register of concluded directions (including the junction-repair and memory-strategy negative results) — are reusable independently of our system. Any agentic pipeline, in any domain, can adopt the same discipline: profile before you optimize, gate before you claim, match budgets before you compare. We anticipate that calibrated agency will become more, not less, important as agents grow more capable, because each added capability enlarges the space of plausible-sounding but unverified actions.

## Methods

### System architecture

RNADesignAgent is implemented as seven layers. L0 (tools): 54 tools, each defined by a Pydantic-typed specification (identity, version, endpoint, capabilities, limitations) and exposed through one of 22 local FastAPI microservices (ports 8003–8024), one per external code family, each with its own environment and local model weights; 20 external research codes are vendored under `external_repos/` (17 as registered git submodules). L1 (capabilities): thin wrappers that validate tool outputs against their specifications and write audit records (unique per-parameter result keys, per-call timings) into the shared state. L2 (workflows): eleven domain workflows (mRNA CDS design, full-length mRNA design, mRNA sequence scoring, siRNA design, sgRNA design, ASO target screening, IRES prediction, RNA aptamer design, RNA secondary-structure design, RNA tertiary-structure design, RNA–small-molecule interaction), all subclasses of a base workflow enforcing a generate → evaluate → score → rank skeleton with progress events and partial-rerun support. L3 (service orchestration): a service manager mapping each workflow's declared `required_capabilities` to microservices, with file-locked, health-check-gated auto-start that distinguishes a busy service (port listening, health probe starved) from a dead one. L4 (multi-agent execution): a deterministic PipelineAgent scheduling pipeline nodes; per-workflow SpecialistAgents owning retry decisions; a deterministic CoordinatorAgent running a bounded coordination loop for the two coupled workflows (retained as an auditable budget-allocation mechanism with hard round caps, clamped parameter adjustments and full traces; evaluated and not credited with a coordination benefit — Results); an advisory QualityAgent issuing per-workflow quality reports (three deterministic workflows are explicitly exempt, since retrying fixed inputs cannot change outputs); and a SynthesisAgent for multi-node reports. L5 (session/workspace): per-session workspaces with context-propagated session IDs and cross-turn result history. L6 (entry): a form-driven CLI and FastAPI façade through a unified runner; workflow selection is explicit, and user-supplied parameters are sanitized against workflow input models.

### Calibrated-agency stack

The SelfModel maps each (oracle, task type, target family) tuple to one of four capability grades (screening / ranking / docking / none) with evidence pointers and confidence. The CapabilityProfiler computes grades from anchor-set evaluations against pre-registered thresholds (screening AUROC > 0.8; ranking Spearman ρ ≥ 0.6; docking native top-1 in ≥ 2/3 cases), with a deterministic driver backend. The DecisionGate intercepts planned actions and forbids those whose evidentiary basis is absent (for example, ranking by an oracle with no ranking grade); the ClaimGate intercepts outgoing claims and downgrades them along a scope ladder (absolute → same-target relative → trend-only → suppressed), enforcing "no claim without verification". Both gates are deterministic; every decision is appended to an append-only JSONL audit trail. Anchor sets are assertion-curated: entries carry role labels (binder, negative, unrankable), internal consistency assertions and negative assertions are checked at build time, and coverage (≥ 4 binders and ≥ 3 negatives per target) is verified before use. mRNA-side anchors follow the same pattern with measured continuous labels (mean ribosome load) substituted for affinities, dichotomized at pre-registered pool extremes (top versus bottom 60 of the read-depth-filtered pool) for the screening grade, with a 120-anchor rank-stratified subset per family for the ranking grade.

### Generation-layer constraint navigation (GenNav)

GenNav comprises four components: (1) a feasibility-first adaptive probe over the generator's gear lattice that determines which gears are feasible for a target before budget allocation, with an explicit degrade path when no gear is feasible; (2) profile-orthogonal generation axes so that design profiles are separable by construction; (3) a diversity expander enforcing a minimum pairwise edit distance within delivered batches; and (4) explicit generator-context resolution (for mRNA, species-matched codon tables; for aptamers, length and seed gears). Ranking is mechanized: the system enforces utility order and the LLM arbitrates ties only. Constraint matrices are pre-registered per campaign (mRNA E5/E6 matrix: GC content windows, homopolymer runs < 14 bp, initiation-region stems ≤ 12 bp, full-length stems ≤ 30 bp, boundary GC, CAI ≥ 0.8; aptamer E8 matrix: global GC ∈ [0.35, 0.70], homopolymer runs < 6 nt, LinearFold longest stem ≤ 12 bp, per-profile length bands compact 25–39 / standard 40–60 / extended 61–85 nt, and a within-batch normalized edit distance ≥ 0.15 among the five delivered candidates per profile). For mRNA, the gear lattice is the LinearDesign λ set {0, 2, 8, 20, 50} with profile-orthogonal axes (CAI-maximizing, fractional, floor); for aptamers, the lattice is the ODesign (length, seed, sample-count) grid over lengths {25, 30, 40, 50, 65, 80}. The generation budget is identical across arms in every campaign (the budget-matching rule): on aptamers, 48 raw candidates per target per arm, the navigation arm spending at most four targeted request_generate rounds inside the same cap. Aptamer target metadata are assertion-checked before generation: a target's declared hotspot residues are validated against the structure chain's numbering, falling back to automatic hotspot identification on mismatch (one such mismatch, SARS-CoV-2 N, was caught and repaired this way).

### Benchmarks, anchors and experimental campaigns

Benchmarks used: a 210-task platform suite across the eleven workflows; a 20-target full-length mRNA suite (two legacy oversized targets — the ZIKV polyprotein and factor VIII, both beyond the LinearDesign memory guard — replaced by OTC, 354 aa, and PDGFB, 241 aa, with translation-verified RefSeq CDSs); a 20-target aptamer suite; and a 19-task process-aware multi-turn regression suite (also serving as CI). External anchors include BNT162b2/mRNA-1273 full-length sequences, 20 wild-type CDSs with 200 random synonymous controls, known aptamers (TBA, pegaptanib, SARS-CoV-2 N binders), an IRES positive/negative panel, small-molecule binder/non-binder pairs, RNAsmol held-out test splits and decoy case studies, and measured-MRL 5′UTR sets (Sample et al., GEO GSE114002). All comparative experiments followed the pilot-first protocol: pre-registration (hypothesis, primary metric, expected effect size, gate, pilot n recorded in the driver), a small-scale pilot with a decisive control arm, a go/no-go gate, and disciplined recording of negative pilots as evidence. The budget-matching rule — equal total generated-and-evaluated candidates across arms for any best-of-pool or hypervolume comparison — was enforced in P0, P3, E4, E6 and E8. The E3-M mRNA audit set (`experiments/e3_mrna/audit_tasks_mrna.json`) mirrors the E3 construction on real mRNA assets: ten trusted-deterministic tasks whose ground truth is computed by exact recomputation (CAI via Sharp–Li weights on the built-in Homo sapiens Kazusa table; folding energy via LinearFold; constraint satisfaction) and ten untrusted-oracle tasks whose decoy scores are real platform outputs (GEMORNA 3′UTR stability and MRL on never-profiled families; junction metric). The gated arm's SelfModel is preloaded from the E7 profile (`experiments/results/e7_selfmodel/self_model.json`), with deterministic report metrics (cai_metric, mfe_metric, constraint_check) registered per task family and a verified ranking grade implying scoring; both arms make exactly two LLM calls per task at temperature 0.

### Statistics

Paired comparisons used two-sided Wilcoxon signed-rank tests with Cliff's δ as effect size; multiple-testing control used Benjamini–Hochberg FDR. AUROC confidence intervals used 10,000-fold bootstrap. The GenNav primary endpoints used paired McNemar tests on per-profile joint-criteria pass/fail (mRNA: n = 54 pairs; aptamer: n = 30 pairs in the initial transfer, n = 36 pairs = 12 targets × 3 profiles in the decisive campaign). Oracle ranking grades used Spearman correlation against measured values (Kd or MRL). The memory learning-curve endpoint used a one-sided one-sample t-test on per-seed-group slopes. Thresholds were pre-registered per campaign (for example, δ ≥ 0.3 for pilot GO gates; AUROC > 0.8; ρ ≥ 0.6; FDR q < 0.05 with |δ| ≥ 0.3 for design gains).

### LLM usage and cost reporting

The sole external LLM in all reported results is DeepSeek (deepseek-v4-pro; official endpoint; temperature 0.2 for legacy quality reviews, 0.0 for the in-system LLM under test). Measured usages: platform quality-review suite 93 calls (414,088 prompt + 194,261 completion tokens); gating experiment 80 calls; memory campaign 230 calls; mRNA constraint-navigation campaigns 3 (S0), 23 (S1) and 43 (S2) calls; aptamer constraint-navigation campaigns: E8 76 calls (S0 4, S1 12 + 14 across the mechanism-fix rerun, S2 46; mean 4.6 per target at S2) and E14 1 call across the 12-target decisive run (deterministic guarantee allocation); oracle profiling campaigns use no LLM calls. All structure and sequence models run as local microservices with local weights. Experiment orchestration was assisted by the Kimi CLI coding agent, which is not part of the tested system.
